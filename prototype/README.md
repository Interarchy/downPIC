# 浏览器插件交互原型

这是网页图片采集插件的单页交互原型，用于验证首次版权确认、悬浮采集、项目类型切换、连续保存、离线暂存和采集异常反馈。原型用界面状态模拟真实下载，不会在磁盘创建图片文件。

## 启动

在项目根目录运行：

~~~powershell
python -m http.server 4173 --directory prototype
~~~

然后打开：

~~~text
http://127.0.0.1:4173/
~~~

## 自动化测试

~~~powershell
node --test prototype/tests/*.test.mjs
~~~

## 建议测试路径

1. 点击浏览器右上角绿色 `S` 图标。
2. 首次开启时阅读版权边界、勾选确认并开启图片保存功能。
3. 鼠标停留在建筑图片上约 150 毫秒。
4. 保存前两张图片到“文化建筑”。
5. 在第 3 张图片的工具条中切换为“教育建筑”。
6. 继续保存第 3～5 张图片。
7. 再次悬浮已经保存的图片，验证同项目重复状态。
8. 切换项目类型，验证跨项目再次保存。
9. 在始终可见的自定义栏输入纯空格，验证 Save 不可用。
10. 点击“打开桌面应用”，确认新标签页打开 `http://127.0.0.1:4174/desktop-prototype/`。

## 异常场景入口

通过 URL 参数切换采集结果，插件正式界面不增加调试控件：

- `?scenario=offline`：桌面端完全退出，下载后进入离线暂存。
- `?scenario=restricted`：网站限制原图访问，明确提示未保存。
- `?scenario=unsupported`：SVG 或动态图片等格式暂不支持。
- `?scenario=inaccessible`：原图地址失效。
- `?scenario=download-error`：下载中断，可原位重试。
- `?scenario=staging-error`：浏览器暂存失败，可检查权限后重试。

## 已知限制

- 以交互状态模拟真实下载，不写入磁盘。
- 不创建本地文件夹。
- “打开桌面应用”连接到本地桌面端交互原型，不连接真实 Windows 进程。
- 不解析真实网站图片。
- 页面刷新后模拟保存状态会清空。
