# ArchBuddy 断点环草图版三方案独立核查（2026-10-15）

## 结论

以 `radial-sketch-labels2-20261015` 页面资源和 `?round=8c` 为基准，三版可供本地比较；未发现阻断问题。本核查未修改页面源文件，亦不代表已同步正式展示页或部署公网。

## 图面核查

- 内侧绿色流程线位于绿色扇环内部，从扇环内缘向外移约三分之一带宽，而非落在中心白圈：1440 宽为 37/112px，1024 为 31/94px，390 为 22/67px，360 为 20/61px。
- A/B/C 三个断口均是双端圆角的浅红描边胶囊，自流程线半径向扇环外缘延伸；流程线以内约三分之一的环带留白。A/B/C 字母嵌在胶囊内，没有独立的图面圆圈。
- 胶囊内的白点按半径和角度生成，向外放射；不是横竖网格。三版每个场景分别生成 75/45/108 个点。对应证据见 `one-1440.png`、`two-1440.png`、`three-1440.png`。
- 绿色流程线和三处箭头同色、同一环径；箭头分别停在三处断口前。五个扇面间有可见白缝，颜色从浅至深；方案 2 的扇面白缝更宽、胶囊更浅，方案 3 的色阶和点阵更强。
- 五个步骤的文字已从流程线外移，并在最终版把 02/05 拆为两行。最终 1440/1024/390/360 四种宽度截图中，没有文字与绿线交叠。02、05 在桌面和手机均分两行并收在扇环内，桌面字号恢复到 16px（1024px 为 15px）；各宽度中它们都与流程线、扇环外缘保持空隙。

## 浏览器核查

Chrome + Playwright 逐一打开三版，测试宽度 1440、1024、390、360px，共 12 个场景。所有场景 `body.scrollWidth` 等于视口宽度，console error 与 pageerror 均为 0。点击三版按钮、直接访问 hash、键盘 ArrowRight/Home/End 均切换到对应的单选状态和点阵密度。各宽度截图为 `one/two/three-{1440,1024,390,360}.png`，数据见 `metrics.json` 与 `interactions.json`。
