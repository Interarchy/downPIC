# 01 断点环三版视觉比较 · 2026-10-15

## 目标

用户认为上一轮暗红斜线与环形不协调，内侧绿色线过于贴近环带边缘。只在本地比较三种断口表达，保留五步顺时针、A/B/C 三处工作断点和右侧三类痛点；正式展示页与公网均不改。

## 统一几何与视觉语言

- 延续 ArchBuddy 的纸白 `#F5F7F4`、森林绿 `#153B2D`、品牌绿 `#25634B`、浅绿环带和低饱和暗红 `#A55442`，字体沿用 Segoe UI / 微软雅黑 / 苹方；不复制彩虹信息图。
- 环带断口统一为 33–42°、105–114°、249–258°。每版流程线都向圆心内收约环带厚度的三分之一，与三个断口共角度；每处环线末端有顺时针箭头，表达流程尝试继续但被打断。05 到 01 的连接保留。
- 中心仅「创作流程／断点分析」两行；右侧只列 A/B/C 与保存打断思路、意图难以表达、成果难以复用。五个步骤与右侧文案保持不变，便于直接比较断口表现。

## 三种候选

1. **轻点网**：白底缺口里完整铺稀疏暗红细点。强调断裂而不引入大块红色；整图最克制。
2. **留白点桥**：大部分缺口保留空白，只在中段布置一个小点群；箭头最清楚，图面最轻。
3. **反白点阵**：断口填柔和暗红，使用浅色微点减轻重量；识别最快，视觉强调最强。

三版仅为视觉选择，不改变产品逻辑、不引入图片、图标包或云端接口。采用 CSS 环带、点阵及几何箭头；箭头属于流程图连线，不替代产品界面图标。每版桌面与手机都应保证步骤文字不贴线、三个箭头与缺口对应、页面无横向溢出。
