# ArchBuddy 01 · 草图约束下的三种环形断点方案

本地预览：`http://127.0.0.1:8766/mockups/archbuddy-radial-break-options/#one`。顶部可切换均衡放射、轻盈留白、层次点阵；链接中的 `#one`／`#two`／`#three` 可直达三版。用户选定前，正式展示页与公网均不改。

三版均将绿色流程线置于五段绿色扇环的内侧三分之一，而非白色中心区；A/B/C 断口仅占流程线到扇环外缘的约三分之二，内端与流程线对齐。断口是两端圆润、浅红描边的椭圆胶囊，字母嵌在外端，白点按从中心向外的极坐标列排布。五段扇面以窄白缝分隔，按 01→05 从浅绿递进到深绿；流程线与三处箭头同为绿色并连续相接。具体几何及方案差异见 `plan.md`。
