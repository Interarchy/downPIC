# ArchBuddy 01 · 深绿底暖色三版

本地预览：http://127.0.0.1:8766/mockups/archbuddy-radial-break-options/?round=12#one

顶部三个按钮或 #one / #two / #three 切换珊瑚橙、琥珀橙、朱红。三版固定主题深绿章节底和由浅到深的五级扇面色，只比较暖色强调。断点切槽使用色块同一圆角路径做等距扩张，使相邻边平行、净缝约8px；五条细分缝采用相同6px法向宽度（560px图径），不再采用等角缺口。

编号与名称沿同一弧线放大1.15倍；断点字放大1.18倍。流程虚线2.6px，开口箭头随之加大，保持同色同一SVG路径。断点倒角加大，保留外宽内窄；C字形正向，按右到左读“断点C”。
