# ArchBuddy 产品短片第四章：搜索复用

这是约 22.5 秒的网页动效稿，入口为 `/film/scene-04/`。画幅为 1440×810，沿用前两章的深绿背景；画幅外层仅保留“搜索复用”大标题。动态演示使用站点已有图片，不读取真实用户图库、不发起模型请求、不写入剪贴板。

## 镜头节奏

| 时间 | 画面与动作 |
| --- | --- |
| 0–2.4 秒 | 展示完整图词库与密集的图片卡，左侧为图库 / 词库、分组导航。 |
| 2.4–6.5 秒 | 镜头向固定页眉的搜索框轻推，逐字输入“沿水面舒展展开的建筑”。 |
| 7–10 秒 | 点击“语义搜索”，界面切换为四张水岸参考图的匹配结果，镜头回到结果区域。 |
| 10.4–14 秒 | 展开右侧“Prompt 版本历史”，图像与保存的提示词并列，镜头轻微推近。 |
| 14–18.8 秒 | 保留足够阅读时间，看到保存的版本、关联参考图数和完整提示词。 |
| 18.8–22.5 秒 | 点击真实功能“复制此版本”，出现“Prompt 已复制”反馈，定格在可复用的图词资产。 |

静帧复核建议：`?t=1.2`、`?t=6.2`、`?t=10.2`、`?t=16.5`、`?t=21.3`。加入 `&clean=1` 隐藏画幅外预览控件。渲染使用共享 film-player 时间轴；所有状态由时间计算，支持任意时刻复现与重播。

## 真实产品依据

读取并核对 `direction/plugin` 分支的：

- `extension/library.html`：固定页眉的自然语言搜索框与“语义搜索”按钮；图库 / 词库、分组、提示词详情布局。
- `extension/library.mjs`：`renderDetail()` 展示“Prompt 版本历史”、版本下拉、正文、关联参考图，并提供“复制此版本”；`copyVersion()` 成功反馈为“Prompt 已复制”。
- `extension/library-search.mjs`：输入时关键词匹配，提交后使用查询向量补充本地语义候选，合并去重。
- `docs/ARCHBUDDY_PRODUCT_FORM.md`：图词库在插件本地保存参考图、Prompt 版本及对应关系；素材复用属于已有能力，Canvas 自动同步不属于当前运行功能。

镜头压缩了检索等待与局部布局，用演示数据表达搜索和复用；四条匹配结果不是真实模型检索结论。最终通过已证实的“复制此版本”完成复用，不呈现“自动发送 Canvas”“一键同步”等尚未实现的跨端动作。图库采集图片详情的真实入口是“生成全提示词”，没有“加入参考”按钮；本段因此使用词库中已有的图词资产。
