# ArchBuddy 产品短片：第一章《图片快速采集》

这是约 16 秒的可重播网页动效稿，入口为 `/film/scene-01/`。本轮增加保存后的自动收纳动画，并以深绿色下载目录区分左侧网页浏览画面。

## 分镜

| 时间 | 左侧建筑案例网页 | 右侧下载目录 |
| --- | --- | --- |
| 0–1 秒 | 浏览器标签、地址栏及建筑事务所案例页进入。 | 深色目录中已有“滨海艺术馆”“城市公共空间”两个项目文件夹。 |
| 1–4 秒 | 向下滚动到第 1 张图，真实插件浮框出现在图片上方，点击“保存图片”；图片自动缩小并向右收进目录。 | 在“下载 / ArchBuddy / 文化建筑”下新建“水岸文化中心”，接住第 1 张图。 |
| 4–14 秒 | 继续向下滚动到第 2、3、4 张图，逐张点击保存；每张图沿相同方向自动收纳。 | 同一项目文件夹不断增加缩略图，计数从 1 到 4。 |
| 14–16 秒 | 页面停留在第 4 张图，章节文案收束。 | 文件夹显示 4 张图片。 |

## 产品行为依据

- 浮框结构、按钮文案、Logo SVG 与样式取自 `extension/content.js`、`extension/content.css` 的 V4.1 实现；`plugin-toolbar.css` 是当前浮框样式的原样副本，仅在 `scene.css` 中做镜头定位覆盖。
- 插件的 `downloadImage` 以 `ArchBuddy/分类/网页标题/时间戳_图片标题` 为保存路径。因此同一个案例页第一次保存会形成项目文件夹，后续三张进入该文件夹；不会每张创建一个新项目。
- 图片从左向右缩小、飞入目标缩略图的路径是官网短片的视觉表达，不表示用户拖拽，也不表示插件真实界面会播放该效果。
- 左侧网页为虚构的建筑案例站，建筑图像为本轮生成的演示素材，不代表真实第三方网站。右侧为本机下载目录的视觉演示，不代表云同步或 Canvas 自动联动。
- 本动效用于确认叙事与节奏，尚非最终 MP4。正式短片替换为获得授权的真实案例网页和产品录屏。

## 验收

重播时应能看到一页纵向滚动、四次浮框保存、四次由左向右自动收纳、两个预存文件夹、一个新项目文件夹及逐张增加的四张图片。缩放至较窄屏幕仍保持 16:9 镜头比例，尊重系统减少动效设置。
