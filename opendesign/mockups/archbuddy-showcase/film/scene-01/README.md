# ArchBuddy 产品短片：第一章《图片快速采集》

这是约 10 秒的浏览器动效稿，用于核对叙事节奏、视觉风格与“逐张保存到项目”的动作。页面位于 `/film/scene-01/`，点击“重新播放”可复看。

## 分镜

| 时间 | 画面与动作 | 信息 |
| --- | --- | --- |
| 0–1.5 秒 | ArchBuddy 标识、章节标题、建筑案例页面与图词库项目文件夹入场。 | 一个产品内的参考收集。 |
| 1.5–7.3 秒 | 依次选中四张建筑图；浏览器浮框出现，“保存图片”被点击；图片缩小并飞入右侧同一个项目。 | 图片快速、连续地归档。 |
| 7.3–8.0 秒 | 文件夹计数达到 04/04，项目状态显示“4 张参考已归档”。 | 采集结果清晰可见。 |
| 8.0–10.0 秒 | 收束文案“四张参考，一次归档。好参考，顺手收进图词库。” | 为第二章提示词构建留下同一组参考图。 |

## 素材与边界

- 四张建筑参考图为本轮生成的同一水岸文化中心主题演示素材，并非现有用户项目。
- 浏览器页面与插件浮框为动效重构，用于确认节奏；正式短片需替换为真实产品录屏和获授权的网页案例画面。
- 图词库右侧文件夹只表达插件端项目归档，不暗示 Canvas 自动同步或统一账号额度已上线。
- 动效预览不是最终 MP4；确认节奏后可用相同镜头导出视频，并拆出官网滚动章节。
