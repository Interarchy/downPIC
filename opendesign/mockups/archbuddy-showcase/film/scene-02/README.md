# ArchBuddy 产品短片：第二章《快速构建提示词》

独立可重播动效稿，入口为 `/film/scene-02/`，约 16 秒。视觉承接第一章的“水岸文化中心”采集图，从图词库选取三张进入提示词构建。

## 分镜

| 时间 | 动作 | 画面信息 |
| --- | --- | --- |
| 0–4 秒 | 第一张参考图从画面右侧滑到最左侧，图上两项结构化设计维度逐字出现；其右侧浮现淡淡的“＋”。 | 场景与主体、空间与体量。 |
| 4–7 秒 | 第二张从右侧滑到第一张右侧，图上的两项维度逐字出现；再浮现第二个“＋”。 | 视角与构图、景观与配景。 |
| 7–10 秒 | 第三张从右侧滑入第三个位置，两项维度逐字出现。 | 材料与表面、光线与氛围。 |
| 10–16 秒 | 第三张右侧出现箭头，指向最后入场的“整体 Prompt”；六项维度以醒目的标题和两行左右的正文依次汇入。 | 三张参考图组成一份可编辑的提示词。 |

## 产品行为依据

- 插件当前最多支持三张参考图，且各设计维度须由用户选择“加入”整体 Prompt，所以本段以三张参考图和一个组合结果组成四拍。
- 维度名称取自 `extension/shared.mjs` 的 `INTENT_MODULES`；“加入整体 Prompt”“整体 Prompt”“整体确认”沿用现有插件的真实操作概念。
- 图像沿用第一章已生成的演示素材。逐字出现的具体内容是镜头示意，未调用模型、未读取用户图词库，也不代表插件当前会自动选择设计维度。
- 最后一栏用纯文字排版展示完整六项示意维度，去掉旧稿的“预览”字样和绿色准则框。每张图上的两段正文与组合结果中的六段正文，在预览画幅中均渲染为两行。
- 这是官网短片的网页动效稿，尚非 MP4。正式版本应使用获得授权的参考图与产品实录。

## 验收

重播可见三张参考图依次从右侧到达左、中、右三个固定位置；两个浅色加号依次显现，箭头引出“整体 Prompt”；所有正文两行显示，最终三张参考图和六项维度完整出现。减少动效设置下呈现静态最终结果。
