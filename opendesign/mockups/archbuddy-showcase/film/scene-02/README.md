# ArchBuddy 产品短片：第二章《快速构建提示词》

独立可重播动效稿，入口为 `/film/scene-02/`，约 16 秒。视觉承接第一章的“水岸文化中心”四张采集图，从图词库选取其中三张进入提示词构建。

## 分镜

| 时间 | 动作 | 画面信息 |
| --- | --- | --- |
| 0–4 秒 | 第一张参考图由右侧滑入，占据画面约四分之一；图上逐字出现两个设计维度。 | 场景与主体、空间与体量。 |
| 4–7 秒 | 第一张左移、第二张从右侧滑入，内容扩展至约二分之一；第二张的设计维度逐字出现。 | 视角与构图、景观与配景。 |
| 7–10 秒 | 前两张左移、第三张滑入，内容扩展至约四分之三；第三张的设计维度逐字出现。 | 材料与表面、光线与氛围。 |
| 10–16 秒 | 三张参考图再左移，右侧出现“整体 Prompt 预览”，六个选中的维度依次汇入，最终占满四栏。 | 三张参考，汇成一个可编辑的 Prompt。 |

## 产品行为依据

- 当前插件最多使用三张参考图进行提示词构建，所以本段使用三张图；第四栏是组合结果，不虚构第四张输入。
- 维度名称取自 `extension/shared.mjs` 的 `INTENT_MODULES`；“加入整体 Prompt”“整体 Prompt 预览”“整体确认”沿用现有插件的真实操作概念。
- 图像沿用第一章已生成的演示素材。所有打字文案为镜头示意，未调用模型、未读用户图词库，也不代表插件当前会自动选择设计维度。短片用动画表达用户选择并组合的过程。
- 这是官网短片的网页动效稿，尚非 MP4。正式版本应使用获得授权的参考图与产品实录。

## 验收

重播可观察到四个连续节拍：25%、50%、75%、100%；前三张参考图均自右向左滑动并逐字显示两项结构化内容；第四拍显示六项汇总与“整体确认”入口。系统设置减少动效时呈现完整静态结果。
