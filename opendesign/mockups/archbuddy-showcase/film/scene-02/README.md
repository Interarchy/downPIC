# ArchBuddy 产品短片：第二章《快速构建提示词》

独立可重播动效稿，入口为 `/film/scene-02/`，约 16 秒。视觉承接第一章的“水岸文化中心”采集图，从图词库选取三张进入提示词构建。

## 分镜

| 时间 | 动作 | 画面信息 |
| --- | --- | --- |
| 0–4 秒 | 第一张参考图从画面右侧滑到最左侧，图上文字按“图像标签 → 维度标题 → 正文”自上而下逐项出现；其右侧浮现清晰的“＋”。 | 场景与主体、空间与体量。 |
| 4–7 秒 | 第二张从右侧滑到第一张右侧，图上的两项维度依次从上到下出现；再浮现第二个清晰的“＋”。 | 视角与构图、景观与配景。 |
| 7–10 秒 | 第三张从右侧带轻微透视滑入，三张图保持相同高度、尺寸和向右的透视角度，并以明确间距排列；两项维度依次出现。 | 材料与表面、光线与氛围。 |
| 10–16 秒 | 第三张右侧出现箭头，指向更宽的“整体 Prompt”；六项维度按标题、正文的顺序自上而下汇入。 | 三张参考图组成一份可编辑的提示词。 |

## 产品行为依据

- 插件当前最多支持三张参考图，且各设计维度须由用户选择“加入”整体 Prompt，所以本段以三张参考图和一个组合结果组成四拍。
- 维度名称取自 `extension/shared.mjs` 的 `INTENT_MODULES`；“加入整体 Prompt”“整体 Prompt”“整体确认”沿用现有插件的真实操作概念。
- 图像沿用第一章已生成的演示素材。逐字出现的具体内容是镜头示意，未调用模型、未读取用户图词库，也不代表插件当前会自动选择设计维度。
- 右侧宽面板用纯文字排版展示扩充后的六项示意维度。每张图的图像标签、维度标题、正文自上而下显现；整体 Prompt 每项先出现标题，上一项正文打完后才出现下一项。两枚加号改为高对比圆形符号。
- 这是官网短片的网页动效稿，尚非 MP4。正式版本应使用获得授权的参考图与产品实录。

## 验收

重播可见三张参考图从右侧带相同方向的轻微透视进入左侧，保持等高等距排列；两个清晰加号依次显现，箭头引出宽幅“整体 Prompt”；卡片与最终面板的标题和正文均自上而下连续出现。画幅外只保留大的章节标题，预览控制留在画幅外。减少动效设置下呈现静态最终结果。
