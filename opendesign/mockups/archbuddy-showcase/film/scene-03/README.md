# ArchBuddy 产品短片第三章：画布创作

24 秒可重播网页动效，入口为 `/film/scene-03/`。延续前两段 1440×810 深绿画幅与大标题。

## 镜头

| 时间 | 画面 |
| --- | --- |
| 0–3 秒 | 真实名称与结构的提示词、参考图片、图像生成节点进入画面，创作提示词逐字呈现。 |
| 3–5 秒 | 文本与图片端口分别连接图像生成，亮线沿正确端口绘制并出现流动光点。 |
| 5–8 秒 | 镜头轻推图像生成，显示两张演示结果。 |
| 8–11 秒 | 镜头跟随 image 连线向右平移，进入方案迭代节点。 |
| 11–15 秒 | V1 第一轮的提示词、两张对应结果逐项归档。 |
| 15–18 秒 | V2 第二轮继续保留新的提示词与结果，V1 留在上方。 |
| 18–22 秒 | 移动第二轮输入与输出图的帘布对照线。 |
| 22–24 秒 | 定格在两轮提示词和图片并列保留的方案迭代节点。 |

静帧参数 `?t=7.6&clean=1`、`?t=14.5&clean=1`、`?t=23&clean=1`；重播与章节导航位于画幅外。

## 真实界面依据

核对 Interarchy/archbuddy-canvas 的 `feature/canvas-workbench`，提交 `e61c1bf8556e50291125706a0b3d311cd84d3b4d`：

- `src/lib/studio/nodeCatalog.ts`：提示词、参考图片、图像生成、方案迭代的名称、宽度、端口契约。
- `StudioNode.tsx`：提示词 text、参考图片 image 分别输入生成节点，生成 image 输出连接方案迭代的“原始生成图”。
- `StudioIterationNode.tsx`、`iteration.css`：原图选择、迭代起点、逐轮归档、提示词快照、输入/输出帘布对照、继续优化入口。
- 方案迭代采用纵向 V1/V2 记录，不虚构横向版本切换、覆盖历史或“应用版本”操作。展示两张结果时节点按真实规则由650px扩展至860px。
- 外层背景沿用短片，节点配色和布局取自产品。连线只在宣传动效中加入辉光和沿线光点；没有改动 Canvas 的实际连线。

## 素材与边界

图片复用第一段的建筑演示素材，以轻微色调差异表达两轮光照和材质调整；不是实时模型生成结果。镜头压缩生成等待，未调用模型、读取真实项目或接入跨端自动同步。

这是 HTML/CSS/JS 动效稿，尚未导出 MP4。通过共享时间轴支持确定时刻截图、重播及减少动效设置。图标复用已有 Lucide sprite；不修改 Canvas、扩展或官网生产站。
