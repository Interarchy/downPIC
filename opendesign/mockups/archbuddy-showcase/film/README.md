# ArchBuddy 滚动式四步设计链路

入口：`/film/`。按用户最新反馈，将88秒连续播放改成原生纵向滚动控制的四个章节。不是要求用户等待固定时长的视频；滚动推进，停下细看，反向回看。

## 页面组织

- 一个固定舞台贯穿四章；页面总长660svh，其中560svh为滚动行程。四章均分行程，浏览速度由用户决定。
- 舞台使用CSS sticky固定，内层内容随章节进度由90%放大到100%；不拦截滚轮、不调用preventDefault、不强制自动跳屏。
- 上方四步导航、进度滑杆和“下一步”可直接定位。可选“播放本段”按短版时间自动演示当前章节，到章末停止；滚轮或触摸会立即停止自动演示。
- 进入下一章时，以参考图、连接的画布节点、8张不同图片组成的图词库承接。概览画面随滚动退出，并交接到实际功能界面。
- 缩短后的核心演示为8、12、16、14秒，仅用于可选自动演示和独立章节的时钟；滚动浏览没有固定观看时长。

## 本轮视觉调整

1. 四章背景统一；大标题去掉句号，动作解说由21px提高到32px，字距保持舒展，按动作逐字出现。
2. 第一章保留首次保存和自动建文件夹的完整逻辑，加快后续三次重复采集与收纳；四张图片最终仍进入同一项目文件夹。
3. 第二到第三章改为四个节点示意：提示词、参考图片、图像生成、方案迭代；发亮连线表达文字与图片共同输入生成，再进行优化。没有使用原来的Prompt扉页。
4. 画布开场镜头略微放大、向左聚焦；右侧方案迭代节点在镜头移向该区域前隐藏，避免开场出现被截断的节点。最终仍保留真实纵向V1/V2提示词及图片记录。
5. 第三到第四章使用大框图词库，内含8张不同图片：6张取自既有建筑库截图的不同区域，2张为已有水岸演示素材的不同视角。
6. 语义搜索增加局部放大画面：40px搜索文字，原输入框与放大框同步；背景轻暗，搜索完成后收回，恢复匹配结果及提示词版本详情。

## 实现与范围

- 继续使用静态HTML/CSS/JS与已有图片、Lucide图标和品牌资产；无新运行依赖。
- `series.js`将原生页面滚动映射到四章确定时刻渲染；`shared/film-player.js`以分段时间映射压缩既有动作；`shared/film-captions.js`集中维护大字解说。
- 独立章节入口保留。独立章节支持`?t=秒数&clean=1`；主入口支持`?q=0到4`定位滚动进度，或`?scene=1到4`定位章首。
- 主入口关键位置：`?q=0.5`快速采集、`?q=2.07`节点连接概览、`?q=2.2`画布开场、`?q=3.07`8图图词库、`?q=3.4`搜索局部放大。
- 用户指定的视觉参考为[Apple MacBook Pro官网](https://www.apple.com/macbook-pro/)，本轮采用固定舞台、滚动推进与关键区域放大的组织方式，不复制其素材。
- 搜索和图片为演示，未调用模型、真实检索、剪贴板或跨端同步；不修改插件、Canvas运行代码、CloudBase或官网生产域名。
