# ArchBuddy 滚动式四步设计链路

入口：`/film/`。按用户最新反馈，将88秒连续播放改成原生纵向滚动控制的四个章节。不是要求用户等待固定时长的视频；滚动推进，停下细看，反向回看。

## 页面组织

- 一个固定舞台贯穿四章；页面总长660svh，其中560svh为滚动行程。四章均分行程，浏览速度由用户决定。
- 舞台使用CSS sticky固定，内层内容随章节进度由90%放大到100%；不拦截滚轮、不调用preventDefault、不强制自动跳屏。
- 上方四步导航、进度滑杆和“下一步”可直接定位。可选“播放本段”按短版时间自动演示当前章节，到章末停止；滚轮或触摸会立即停止自动演示。
- 进入下一章时，以参考图叠层、两路输入汇合生成的抽象关系图、8组图词资产及提取关系承接。概览画面随滚动退出，并交接到实际功能界面。
- 缩短后的核心演示为8、12、16、14秒，仅用于可选自动演示和独立章节的时钟；滚动浏览没有固定观看时长。

## 本轮视觉调整

1. 四章背景统一；大标题去掉句号，动作解说由21px提高到32px，字距保持舒展，按动作逐字出现。
2. 第一章保留首次保存和自动建文件夹的完整逻辑，加快后续三次重复采集与收纳；四张图片最终仍进入同一项目文件夹。
3. 第二到第三章采用抽象分析图：参考图片平面和提示词线条汇入节点，连续发光实线连接生成图，生成图后方以两层轮廓表达版本迭代；扉页不出现节点控件、参数或按钮。
4. 画布开场镜头略微放大、向左聚焦；右侧方案迭代节点在镜头移向该区域前隐藏，避免开场出现被截断的节点。最终仍保留真实纵向V1/V2提示词及图片记录。
5. 第三到第四章用8组图片与文字组成具有一致透视的图词资产阵列，经语义检索取出一组图词；去掉具体应用窗口。素材仍为6张已有建筑库截图区域和2张水岸不同视角。
6. 语义搜索保留40px文字的局部放大画面，与原输入框同步；放大框在结果出现前退出。主界面镜头始终固定，四项结果出现后仅版本详情由右向左滑入，随后描亮提示词边框；静态保留“复制此版本”，不模拟点击或显示复制成功。
7. 第二章取消舞台共享透视，使三张参考卡片投影宽高一致。加号根据首张的实际可见中心与相邻卡片间距定位，在舞台缩放下仍保持居中。

## 实现与范围

- 继续使用静态HTML/CSS/JS与已有图片、Lucide图标和品牌资产；无新运行依赖。
- `series.js`将原生页面滚动映射到四章确定时刻渲染；`shared/film-player.js`以分段时间映射压缩既有动作；`shared/film-captions.js`集中维护大字解说。
- 独立章节入口保留。独立章节支持`?t=秒数&clean=1`；主入口支持`?q=0到4`定位滚动进度，或`?scene=1到4`定位章首。
- 主入口关键位置：`?q=0.5`快速采集、`?q=2.07`汇合生成分析图、`?q=2.2`画布开场、`?q=3.07`图词资产提取分析图、`?q=3.4`搜索局部放大。
- 用户指定的视觉参考为[Apple MacBook Pro官网](https://www.apple.com/macbook-pro/)，本轮采用固定舞台、滚动推进与关键区域放大的组织方式，不复制其素材。
- 搜索和图片为演示，未调用模型、真实检索、剪贴板或跨端同步；不修改插件、Canvas运行代码、CloudBase或官网生产域名。

## 检查

- 修改脚本语法解析通过。
- 同一静态代码和公开演示资产在隔离浏览器中检查：四章均为32px解说，无标题句号；短版时间为8/12/16/14秒。
- 12个定位点跨章与回退无脚本异常。原生scrollTo前进/回退检查中，固定舞台顶部始终为同一位置；自动演示推进、滚轮停止演示均通过。
- 两张抽象扉页及第四章结尾已目视核对；连续连接线无虚线，图词资产阵列保留8组不同图片。第二章两处加号相对相邻投影中心的水平/垂直误差均小于0.02px（1440px舞台）。
- 第四章从结果出现到结尾并回退共7个采样位置：外层scale(1)、内层translate(0,0) scale(1)，四项结果边界保持一致；版本面板128px→0滑入，提示词描边0→1，不存在复制成功提示或按压状态。父页与4章脚本错误均为0。
- 已目视核对上述关键帧。父页面与四个章节脚本错误均为0。真实用户设备上的滚动手感仍可在预览中继续微调。
