# ArchBuddy 四章连续动效

入口：`/film/`。约 87.6 秒，包含四章和三次 2.2 秒内容衔接；这是 HTML/CSS/JS 连续动态预览，尚未导出 MP4。

## 统一视觉与解说

- 四章使用同一深绿色径向渐变和低对比网格，取消第二章独有的装饰圆弧、第一章原有品牌页眉和画幅底部说明。
- 大标题统一58px，字距从负值改为0.035em；右侧21px简短解说，根据当前动作逐字出现。每句约0.8–1.45秒打完，其余时间保留供阅读。
- 解说共21条：采集5条、构建5条、创作6条、复用5条。文案与时间点集中在 `shared/film-captions.js`。
- 图像和主要界面保留已确认的布局。第一章浏览区域增加高度，标题与内容顶边统一。

## 连续链路与转场

| 时间 | 内容 |
| --- | --- |
| 0–16 秒 | 图片快速采集：浏览案例、浮框保存、自动建立文件夹、依次收纳。 |
| 16–18.2 秒 | 采集 → 构建：保留同组参考图的视觉线索，以三张图引出设计语言。 |
| 18.2–36.7 秒 | 快速构建提示词：主体体量、视角景观、材料光线依次加入，构成完整 Prompt。 |
| 36.7–38.9 秒 | 构建 → 创作：整体 Prompt 卡片承接到文字与图片输入。 |
| 38.9–62.9 秒 | 画布创作：输入、连接、生成、第一轮与第二轮优化、历史对照。 |
| 62.9–65.1 秒 | 创作 → 复用：版本记录退场，回到图词库，再次寻找参考。 |
| 65.1–87.6 秒 | 搜索复用：描述特征、语义搜索、查看版本及关联图片信息、复制提示词。 |

转场保持同一背景，上一章淡出、承接内容轻移、下一章淡入。第三处表达使用链路，不演示 Canvas 向插件自动同步或上传。

## 播放与检查

- 四个章节预载，同一主时间轴控制，支持暂停、继续、从头播放、进度拖动和章节跳转。
- 第一、二章由计时器改为确定时刻渲染，原有入场顺序、收纳动效和逐行文字保留，以保证暂停与跳转后状态正确。
- 独立章节继续可访问，并链接回四章连播。共享播放器支持 `?t=秒数&clean=1`；连续入口也支持同样的静帧参数。
- 总片关键帧：`?t=6.2&clean=1`、`?t=17.05&clean=1`、`?t=35.5&clean=1`、`?t=37.8&clean=1`、`?t=61.9&clean=1`、`?t=63.9&clean=1`、`?t=86&clean=1`。
- 脚本语法解析通过；隔离浏览器使用相同静态代码与公开演示资产，检查四章的背景/标题/解说、16个时点、关键转场和实际跨章播放。父页面与四个章节脚本异常均为0，标题与解说无重叠。
- 该预览不调用模型、真实搜索或剪贴板，也不修改插件、Canvas、CloudBase 或官网生产域名。图片、搜索结果及提示词均为演示素材。
