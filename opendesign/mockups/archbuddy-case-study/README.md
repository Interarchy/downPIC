# ArchBuddy 五页产品案例（图解优化版）

## 本轮用户反馈与调整
用户认为初版文字过多、内容均质，要求放大关键标题，以流程图和分析图说明工作断点及插件串联后的链路。

- 每页保留一个核心结论，主标题放大；详细依据与边界放入可展开项。
- 移除装饰性建筑图片，真实界面只用于第三页操作演示。
- 第一页：采集 → 找回 → 构建 → 评估 → 复用链路，标注外部生图及资产回流。
- 第二页：旧工作流的三处断点与 ArchBuddy 的连通链路上下对照；窄屏左右并列，点击断点查看解释。
- 第三页：五步真实界面导览，减少每步正文，保留截图放大。
- 第四页：AI/规则/设计师分工、检索机制与产品边界图；局部材料替换示例收进展开项。
- 第五页：产品演进图、已实现证据与待验证价值分层。

## 使用与移植
- 直接用浏览器打开 index.html，或访问 http://127.0.0.1:8766/mockups/archbuddy-case-study/ 。
- 本地服务命令：node opendesign/serve.mjs。只绑定 127.0.0.1，未部署公网。
- 五个 HTML 与 CSS/JS/图片全部在该目录内，无在线字体、框架或模型依赖；复制整个目录即可作为个人网站的项目子目录。
- 便携包：opendesign/exports/archbuddy-case-study.zip。
- 初版保留在 opendesign/archive/archbuddy-case-study-v1，原预览地址展示优化版。
- assets/tokens.css 是作品集设计系统的便携副本。
