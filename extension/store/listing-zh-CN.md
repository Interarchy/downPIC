# Chrome 应用商店文案（zh-CN）

## 名称

downPIC — 参考图下载与中文提示词反推

## 简短说明

为设计师保存并分类网页参考图，将选中或粘贴的图片反推为可复用的中文结构化生图提示词。

## 详细说明

downPIC 是面向建筑、室内与景观设计师的参考图工作助手。它把“收集参考图”和“提取视觉语言”放在同一个浏览器侧栏中，让设计师在浏览案例时少做重复整理，更快进入新的生图工作。

主要功能：

- 悬浮网页图片即可保存，或发起提示词反推。
- 图片按项目类型和网页标题自动写入清晰的下载目录。
- 支持文化建筑、教育建筑、办公建筑、社区建筑等默认分类，也可创建自己的类型。
- 支持在侧栏直接粘贴或拖入参考图。
- 从色彩、光照、氛围、材料、环境、场景与图像表现等维度生成中文结构化提示词。
- 结果前置统一生成准则：保持原视角与构图，输出四千像素级高品质建筑效果图。
- 一键复制完整结果，便于继续在生图模型中使用。

隐私与控制：

- 只有用户在插件弹窗中主动开启网页图片工具后，downPIC 才显示图片操作入口。
- 只有用户主动点击反推并确认后，所选图片才会发送至 DeepSeek API。
- 模型凭据只保存在 downPIC 服务端，不写入扩展或用户浏览器。
- 不做广告追踪、行为画像或后台浏览记录收集。

首个 Beta 版本不包含云端素材库、自动入库解析或自然语言检索。

## 单一用途说明

帮助设计师收集网页参考图，并把用户主动选择的参考图转换为可复用的中文结构化视觉提示词。

## 建议分类

生产力工具（Productivity）

## 版本说明 0.2.2

- 首次 Beta 发布。
- 支持网页图片下载、自动目录分类和自定义项目类型。
- 支持选择、粘贴或拖入图片后反推中文结构化提示词。
- 恢复点击 Logo 后的网页图片工具总开关。
- 改为通过 downPIC 后端调用模型，用户无需配置 DeepSeek API Key。
- 保留发送前隐私确认和明确的服务状态反馈。
- 网页浮栏支持选择预设分类和新建自定义分类。
- 下载后可从网页浮栏或侧栏直接在文件夹中显示文件。
- 反推时优先读取原图；截图回退会先隐藏 downPIC 浮栏。
- 下载定位入口保持显示，直到用户点击浮栏外、按 Esc 或切换图片。
- 收紧浮栏留白，统一分类、保存与反推控件的高度、字号和圆角。
