# downPIC Beta 上架检查清单

## P0：提交前必须完成

- [ ] 在 `chrome://extensions/` 以“加载已解压”方式安装，无 manifest 或 service worker 错误。
- [ ] 在至少 3 个普通 HTTPS 图片网页验证启用、悬浮按钮、侧栏和下载。
- [ ] 用服务端配置的 DeepSeek API Key 完成至少 5 张不同类型图片的反推，确认端点和响应结构均可用。
- [ ] 验证结果全部为中文，“整体生成准则”始终第一，至少返回 4 个有效视觉分项。
- [ ] 验证 Logo 弹窗、总开关、粘贴、拖入、复制全部，以及浮栏和侧栏中的预设/自定义分类。
- [ ] 从浮栏和侧栏各下载一张图片，确认“在文件夹中显示”能定位对应文件。
- [ ] 分别测试可直接访问原图和只能截图回退的网页，确认反推预览不包含 downPIC 浮栏。
- [ ] 验证超过 10 MB、服务未启动、模型未配置、模型超时/限流、图片可见区域过小时有可理解的错误提示。
- [ ] 将 `privacy-policy.md` 中的联系邮箱替换为真实邮箱。
- [ ] 将隐私政策部署到公开可访问的 HTTPS 地址，并填入商店后台。
- [ ] 准备至少 1 张 1280×800 或 640×400 的真实功能截图；不要使用纯营销图冒充产品界面。
- [x] 准备 128×128 图标和 440×280 小型宣传图。
- [ ] 在商店后台完成单一用途、权限理由、数据使用披露和审核测试步骤。
- [ ] 腾讯云生产后端已配置鉴权、单用户配额、限流、全局预算熔断和 HTTPS；Key 仅存服务端 Secret。
- [ ] 开发者账号已启用两步验证，开发者资料和支持邮箱可用。
- [ ] 先选择“不公开（Unlisted）”作为 Beta 分发，完成真实安装闭环后再考虑公开。

## 建议的人工验收样本

- 建筑外观日景：检查构图、材料、光照和环境。
- 建筑外观夜景：检查人工照明、色温和氛围。
- 室内空间：检查材料、软装、尺度和光源。
- 景观空间：检查植被、水体、铺装和季节感。
- 非建筑图片：确认模型不会强行编造建筑信息，结果仍可解释。

## P1：上线后首轮更新

- 反推超时、限流与错误状态的更细分提示。
- 下载失败时，对 blob、懒加载或受保护图片提供截图保存兜底。
- 支持对单个提示词分项进行编辑、复制与重新生成。
- 增加本地匿名、可关闭的错误诊断机制前，先完成新的隐私评审。
- 根据真实使用反馈调整右侧常驻面板宽度与网页画面影响。

## 当前硬门槛

本地 Beta 依赖 `127.0.0.1:4186`，只能用于开发测试。公开上架前必须先完成腾讯云后端，把扩展中的公开后端地址和权限切换到生产 HTTPS 域名，并通过真实审核链路验证；不能把本地版直接提交商店。
