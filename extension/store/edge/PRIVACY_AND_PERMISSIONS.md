# Edge 隐私、权限与数据使用填写稿

对应已提交 V4.1 / 0.6.1 的 manifest 与云端匿名使用路径。本稿不包含尚未发布的账号、积分或支付功能。提交时以 Partner Center 实际字段为准逐项核对。

## 单一用途

帮助建筑、室内和景观设计师采集、整理、查找参考图，并把参考图转化为可编辑、可评估、可保存的中文效果图提示词。

## 权限理由

| 权限 | 填写理由 |
| --- | --- |
| `activeTab` | 用户主动选择网页图片并要求反推时，临时读取当前标签页；原图不能直接读取时，仅为定位所选图片截取可见区域。 |
| `scripting` | 网页图片工具开启后，把安装包内脚本和样式注入已打开网页，让保存和反推浮框立即可用。 |
| `sidePanel` | 与当前网页并排展示提示词生成、优化及图词库入口。 |
| `downloads` | 用户主动保存图片至 Edge 下载目录；读取本扩展的下载记录以展示、定位和按确认删除相应原图。 |
| `storage` | 保存开关、分类、同意状态、匿名安装标识、图片与提示词元数据；图片副本、预览及向量索引存于扩展 IndexedDB。 |
| `alarms` | 在用户已开启图库 AI 时，定时恢复新下载图片的视觉描述任务，并受同意与额度控制。 |
| `http://*/*`、`https://*/*` | 在不同设计网站显示可由用户关闭的图片操作入口，处理用户选择的图片及来源；不会因访问网页而自动上传整页或浏览历史。AI 仅请求固定的 ArchBuddy HTTPS 服务。 |

## 远程代码

选择“否”。Manifest V3 执行代码均在安装包内；后端返回模型结果与向量数据，不提供需在浏览器执行的远程 JavaScript 或 WebAssembly。

## 数据使用披露依据

- **持久匿名标识与短期会话凭据**：用于 ArchBuddy 自有服务的匿名鉴权、每日额度和防滥用；不读取其他网站账号或密码。
- **所选网站内容和用户提供的内容**：所选图片、生成图、提示词、视觉描述和搜索文本。对应 AI 功能在用户同意后才把必要图片或文本经 ArchBuddy 服务发给 DeepSeek 或腾讯云 TokenHub；模型密钥留在服务端。
- **来源与下载记录**：采集网页地址、标题、下载记录和本地路径用于本地归类、查看或回访；不建立浏览历史，不把来源网址或文件路径交给模型。
- **功能事件和服务记录**：可选匿名产品事件默认关闭；服务端保留必要的匿名请求状态、时长与数值 Token 用量以执行额度和故障处理，不包含图片、提示词正文、网页地址或下载路径。目标保留 30 天，自动到期清理尚未验证，故不可声称已自动删除。
- **本地数据**：图库、提示词及向量索引保存在 Edge 扩展本地；没有账号私有图库或跨设备同步。清除数据/卸载可能丢失记录，下载原图不随卸载自动删除。

不出售数据，不用于广告、跨站画像或信用评估。按后台实际选项如实披露持久匿名标识、网站内容、网络来源和用户活动；即使数据只在本机处理，也不能以“本地”代替披露。Edge 专用隐私页已按同目录 `privacy.html` 发布并核验，可填写 `https://archbuddy-privacy-dev-mel-d9guu8bpu44029179.webapps.tcloudbase.com/edge/`。Chrome 专用在线页面不用于 Edge 草稿。
