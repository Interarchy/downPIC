# ArchBuddy Edge 版发布资料

当前候选版本 **0.7.5 / V5.1**，与Chrome共用最新生产运行文件。构建入口：extension/store/edge/build-edge-candidate.ps1；也可直接运行共用脚本-Browser edge。

本次材料统一见[0.7.5发布目录](../releases/0.7.5/)，其中包含Edge专用商店文案、用户说明及两店权限披露。随包隐私使用extension/privacy.html；本目录旧privacy.html和V4.1截图仅作历史档案，不再参与构建。商店隐私链接优先统一官网https://www.archbuddy.top/legal/privacy/，提交前按清单核对在线正文。

请更新已有Edge商店条目，以保留扩展身份和旧用户数据。不得将未经授权的新随机扩展ID作为正式登录成功的保证。本轮不代为提交商店，也不以隔离Chromium截图冒充真实Edge外壳验收。
