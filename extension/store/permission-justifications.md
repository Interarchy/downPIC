# ArchBuddy 0.6.0（V4）权限与数据披露填写稿

> 对应 `extension/manifest.json` 和 V4 实际数据流。按 Chrome Web Store 后台当前字段填写；不要粘贴测试密钥或真实用户素材。`downloads.open` 已从本版 Manifest 移除，大图在图词库网页内查看。

## 单一用途

帮助建筑、室内与景观设计师采集、整理和检索视觉参考，并生成、优化和保存中文效果图提示词。

## 权限理由

### activeTab

在用户主动选择网页图片并发起反推时，临时访问当前活动标签页；原图不可读取时，截取当前可见区域中的所选图片。不会批量截取或上传其他标签页。

### scripting

用户启用网页图片工具后，将扩展包内的脚本和样式注入安装前已经打开的当前网页，使保存与反推浮框立即可用；不加载远程代码。

### sidePanel

展示图词库入口、提示词生成和效果优化流程，与当前网页并行使用。

### downloads

将用户主动保存的网页图片写入 Chrome 下载目录，按项目分类；读取属于 ArchBuddy 的下载记录以展示图库、定位原文件夹，按用户明确选择删除图库记录或对应原图。导入本地文件夹不会移动或删除电脑中的源文件。

### storage

在 `chrome.storage.local` 保存分类、开关、同意状态、随机安装标识、图库与方案元数据；在扩展 IndexedDB 保存图片副本、缩略预览、提示词方案和本地向量索引；在会话存储保存短期凭据和当前工作状态。模型 Key 不保存在扩展中。侧栏只展示最近五份已确认方案，完整已确认词库保留在本地，直到用户删除或浏览器清理。

### alarms

定时恢复用户已开启图库 AI 后的新下载图片描述任务。下载或导入本身不因此自动把导入图片批量上传给 AI；任务受用户同意、额度和限流控制。

### http://*/* 与 https://*/*

扩展需在不同设计网站显示由用户开关控制的图片操作入口，读取用户选择的图片及其来源以下载或反推；只在用户启用相关功能时处理对应内容。内容脚本可能随普通网页加载，但不会因此自动上传整页或浏览历史。AI 请求只发往固定的 ArchBuddy HTTPS 服务，再由服务调用 DeepSeek 或腾讯云 TokenHub。

## 远程代码

选择“否”。扩展包包含全部执行脚本、样式及界面。后端返回模型数据和向量，不向浏览器提供可执行 JavaScript、WebAssembly 或待执行字符串。

## 用户数据类型与用途

- **网站内容**：用户主动选择、粘贴或拖入的图片；效果优化时主动提供的生成图；图库 AI 开启后新下载图片的限宽预览；用户主动导入的本地图片副本。图片在本地展示与保存，只有对应 AI 功能需要时才发送所选图片或预览至 ArchBuddy 与 DeepSeek。
- **网站活动或网络记录**：当前所选图片的来源地址、当前网页标题及下载记录在本地用于命名和归类；不建立浏览历史档案，不把来源网址和本地路径发送给模型。
- **用户提供的内容**：视觉描述、搜索查询、提示词及其版本。图词库和向量索引在本地保存；开启向量检索后，图片名称、分类、描述和提示词文本在建立或更新索引时经 ArchBuddy 服务发送给 TokenHub，每次提交搜索发送本次查询生成向量。TokenHub 不接收图片字节、来源网址或文件路径。
- **用户活动**：可选匿名改进统计默认关闭；启用后只记录白名单功能事件，不含图片、网址、Prompt 正文、文件路径或自定义分类。服务端另有匿名额度和请求记录，用于配额及防滥用。

仅选择“应用功能”及必要的服务保护用途。不出售数据，不用于广告、跨站画像、信用评估或与产品单一用途无关的目的。即使数据只在本机处理，也如实披露。具体第三方、保留和删除边界见隐私政策。

## 审核员测试

1. 安装扩展，无需登录或配置 API Key。
2. 在普通 HTTPS 图片网页打开浮框，保存一张图，观察下载分类；在侧栏打开图词库。
3. 图词库可查看图片、项目和大图；开启图库 AI 并另行确认向量处理后，输入关键词立即匹配，按回车发起语义搜索。
4. 选择或粘贴参考图，确认图片处理后生成提示词；导入生成效果图并点击“开始评估”，确认新版本入库。
5. 关闭网页浮框或图库 AI 后，检查相应自动处理停止；导入本地测试文件夹不会改变源文件。

## 2026-10-01：商店数据使用复选框映射

按当前 0.6.0 数据流填写：

| 商店选项 | 填写 | 对应处理 |
| --- | --- | --- |
| 个人身份信息 | 勾选 | 随机安装标识及派生的持久匿名标识，用于区别安装、业务额度和防滥用；不收集姓名、邮箱或身份证。此归类基于持久标识的实际用途，不把匿名等同于无用户数据。 |
| 身份验证信息 | 勾选 | 自有服务的短期匿名会话凭据，在扩展会话存储保存并用于服务请求鉴权；不读取其他网站账号或密码。 |
| 网络记录 | 勾选 | 所选图片来源网址、网页标题与有关下载记录，在本地用于归类和命名；不采集完整浏览历史。 |
| 用户活动 | 勾选 | 用户可选择启用的功能事件，以及服务请求结果和额度记录；不记录鼠标轨迹、按键内容或整页行为。 |
| 网站内容 | 勾选 | 所选图片、描述、用户输入的查询与提示词；对应图片或文本仅在已披露的 AI 功能需要时处理。 |
| 健康信息、财务和付款信息、个人通讯、位置 | 不勾选 | 当前没有这些专门的数据采集或用途；不是依据用户可能输入任意内容扩张类别。 |

下方三个 Limited Use 承诺均勾选，内容与现有隐私政策一致。官方说明要求即使仅本地处理也披露：https://developer.chrome.com/docs/webstore/program-policies/user-data-faq 。上面的具体类别映射来自当前代码与该页面选项的核对，不代表审核通过。
