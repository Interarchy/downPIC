# 权限与数据披露填写稿

以下内容用于 Chrome 应用商店后台。提交时应按后台实际字段粘贴，不要扩大描述。

## 单一用途

帮助建筑、室内与景观设计师收集其主动选择的网页参考图片并按项目类型下载分类，将参考图转换为可编辑的中文结构化视觉提示词，并在用户确认后对照单张生成图迭代下一版本。

## 权限理由

### activeTab

仅在用户点击扩展图标或网页图片操作按钮时访问当前活动标签页；当原图无法直接读取时，截取用户主动选择图片的可见区域供反推使用。不访问非活动标签页。

### scripting

用于在用户开启网页图片工具后，向安装前已经打开的当前标签页注入扩展随包提供的图片操作界面。所有脚本均包含在扩展包内，不下载或执行远程代码。

### sidePanel

用于在浏览器右侧展示图片采集、提示词构建、单图效果评估、建议编辑与本地版本记录，避免遮挡当前网页主要内容。

### downloads

用于将用户主动点击保存的图片写入 Chrome 下载目录，并按项目类型与网页标题生成子目录和文件名。

### storage

仅在浏览器本地存储网页图片工具开关、分类、隐私确认、随机安装标识、最多 5 份提示词方案及版本、来源图元数据和匿名统计选择；完整来源原图保存在扩展 IndexedDB，不上传云端。会话存储当前选择图、单张生成图、评估报告、工作草稿和短期匿名凭据。模型 API Key 不进入扩展或浏览器存储。V3 未请求 `unlimitedStorage` 或其他新增权限。

### http://*/* 与 https://*/*

ArchBuddy 面向不同设计网站，需要在普通 HTTP/HTTPS 页面识别用户当前指向的内容图片、显示保存与反推按钮，并在原图不可直接读取时截取用户主动选择的可见区域。工具关闭时不显示操作入口；只有用户主动保存或反推时才处理对应图片。模型请求仅发送到固定的 ArchBuddy HTTPS 服务。

## 远程代码

选择“否，我并未使用远程代码”。扩展会向 ArchBuddy HTTPS API 发送用户确认的图片并接收结构化数据，但不会下载或执行远程 JavaScript、WebAssembly 或字符串代码；所有可执行逻辑均包含在提交的扩展包内。

## 用户数据声明建议

勾选的数据类型：

- **网络记录**：仅在用户使用保存或反推功能时，本地读取当前网页标题、页面地址和所选图片地址，用于识别来源、获取图片及生成下载目录；不建立浏览历史列表，不发送给模型。
- **网站内容**：用户主动选择、粘贴或拖入的参考图，以及主动选择的单张生成图。参考图只有在确认反推后发送；生成图只有在效果优化中再次确认并点击评估后发送。方案级来源原图仅保存在本机，不随评估请求上传。
- **用户活动**：仅在用户主动选择加入匿名统计后，记录分析开始、成功或失败类别、模块编辑或停用、Prompt 确认与复制等功能事件。保留 30 天，可随时撤回；不含图片、网址、Prompt、模块正文、自定义文字或直接身份。

其余数据类型不勾选；不收集身份、健康、财务、身份验证、个人通讯或位置数据。

用途：应用功能。

不进行：出售数据、个性化广告、信用评估、广告追踪、跨站行为画像、人工读取用户内容。

传输：只有用户主动反推时，所选图片才发送给 ArchBuddy 服务，并由服务调用 DeepSeek。网页标题、浏览历史和其他网页内容不发送给模型。

三项披露声明全部勾选：不出售或用于未批准用途；不用于与单一用途无关的目的；不用于信用或贷款目的。

## 审核员测试说明

1. 安装扩展，打开一个普通 HTTPS 图片网页。
2. 点击工具栏 ArchBuddy 图标，在弹窗中开启网页图片工具。
3. 将鼠标移到内容图片上，确认出现“保存”和“反推提示词”。
4. 点击“保存”，确认图片保存到 `ArchBuddy/默认项目类型/网页标题/`。
5. 点击“反推提示词”，确认右侧面板出现所选图片；勾选发送确认后点击反推。
6. 确认返回中文分项结果，可选择部分维度并复制完整 Prompt。
7. 打开“效果优化”，选择刚保存的方案，导入一张生成图；确认只预览不调用，勾选“确认发送”后点击“开始评估”。
8. 确认逐维度报告、部分建议选择、直接编辑和“复制后保存版本”可用；历史版本只读。

V3 当前仍是本地待验证代码，尚未重新部署后端或上传商店；正式提交审核前必须先完成真实 Chrome 与真实模型验证并更新审核凭据。本版本不使用远程代码，也没有新增 Manifest 权限。

正式提交前，ArchBuddy 生产后端必须可供审核员直接测试，并具备鉴权、配额和限流。DeepSeek API Key 不得写入 ZIP、审核说明或公开文案。
