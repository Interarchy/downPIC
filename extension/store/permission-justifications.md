# 权限与数据披露填写稿

以下内容用于 Chrome 应用商店后台。提交时应按后台实际字段粘贴，不要扩大描述。

## 权限理由

### activeTab

用户点击 downPIC 图标或网页图片上的操作按钮时，扩展需要访问当前标签页并截取用户主动选择的可见图片区域。

### scripting

用于在用户开启网页图片工具后，立即向安装前已经打开的当前标签页补充图片操作按钮。脚本随扩展打包，不从远程服务器下载或执行代码。

### sidePanel

用于展示粘贴入口、隐私确认、分类设置和中文结构化提示词结果。

### downloads

用于将用户主动点击保存的图片写入 Chrome 下载目录，并按项目类型与网页标题生成子目录和文件名。

### storage

本地存储网页图片工具开关、默认分类、自定义分类和隐私确认状态；会话存储当前图片与分析结果。DeepSeek API Key 不进入扩展或浏览器存储。

### http://*/* 与 https://*/*

网页图片工具需要在不同设计网站上识别用户当前悬浮的内容图片，并通过 `captureVisibleTab` 截取用户主动选择的区域；本地 Beta 还通过 `127.0.0.1` 访问 downPIC 服务。工具关闭时不显示操作入口，也不扫描、保存或上传图片。生产版本将把模型请求改为固定的 downPIC HTTPS API。

## 用户数据声明建议

会处理的数据：

- 用户主动选择、粘贴或拖入的图片。
- 为下载分类而在本地使用的网页标题、来源地址和项目类型。

用途：应用功能。

不进行：出售数据、个性化广告、信用评估、广告追踪、跨站行为画像、人工读取用户内容。

传输：只有用户主动反推时，所选图片才发送给 downPIC 服务，并由服务调用 DeepSeek。网页标题、浏览历史和其他网页内容不发送给模型。

## 审核员测试说明

1. 安装扩展，打开一个普通 HTTPS 图片网页。
2. 点击工具栏 downPIC 图标，在弹窗中开启网页图片工具。
3. 将鼠标移到内容图片上，确认出现“保存”和“反推提示词”。
4. 点击“保存”，确认图片保存到 `downPIC/默认项目类型/网页标题/`。
5. 点击“反推提示词”，确认右侧面板出现所选图片；勾选发送确认后点击反推。
6. 确认返回中文分项结果，并可复制全部。
7. 在侧栏粘贴图片，重复第 5、6 步。

正式提交前，downPIC 生产后端必须可供审核员直接测试，并具备鉴权、配额和限流。DeepSeek API Key 不得写入 ZIP、审核说明或公开文案。
