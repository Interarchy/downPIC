# ArchBuddy Beta 隐私政策

更新日期：2026 年 9 月 15 日

公开版本：<https://archbuddy-privacy-dev-mel-d9guu8bpu44029179.webapps.tcloudbase.com/>

ArchBuddy 仅处理用户主动选择、粘贴或下载的参考图片，用于提供图片下载、分类和中文结构化提示词反推功能。ArchBuddy 不进行广告追踪、行为画像或后台浏览记录收集。

## 我们处理的数据

下载功能会在用户设备本地使用所选图片、当前网页标题、来源地址和用户选择的项目类型，用于生成下载目录和文件名。提示词反推功能会处理用户主动选择、粘贴或拖入的图片。

## 图片分析与第三方处理

只有在用户主动点击反推并确认图片处理说明后，所选图片才会发送至 ArchBuddy 服务，再由服务调用 DeepSeek API 生成中文结构化提示词。网页标题、浏览历史和其他网页内容不会随图片发送给模型。

DeepSeek 对数据的处理同时受其服务条款和隐私政策约束。用户在使用反推功能前应自行确认其账号、地区与数据使用要求。

## 模型凭据

DeepSeek API Key 只保存在 ArchBuddy 服务端，不包含在扩展程序、网页、下载文件或用户浏览器存储中。用户无需输入模型密钥。

## 匿名身份与额度记录

扩展首次使用时会在本地生成随机安装标识，并向 ArchBuddy 服务换取短期匿名访问凭据。服务端将其转换为不可逆的匿名标识，用于执行个人每日 20 次、ArchBuddy 每日 200 次的额度规则、请求去重和必要故障排查。服务端不保存原始安装标识。

额度和请求记录可能包含匿名标识、日期、请求摘要、成功或失败状态、处理时长及模型返回的数值 Token 用量，不包含图片、提示词正文、网页地址、下载路径或自定义分类文字，目标保留 30 天。ArchBuddy 当前不收集可选产品行为统计；若未来增加，将先更新披露和同意流程。

## 本地保存与删除

分类设置、隐私确认和随机安装标识保存在 Chrome 本地扩展存储中；短期匿名凭据保存在会话存储中。卸载扩展可清除这些本地数据。下载的图片保存在用户的 Chrome 下载目录中，由用户自行管理和删除。

## 数据用途限制

ArchBuddy 不出售用户数据，不将数据用于个性化广告、信用评估或跨站追踪，也不允许人工读取用户图片。

ArchBuddy 对用户数据的使用遵循 Chrome Web Store 用户数据政策，包括其中的 Limited Use（有限使用）要求；数据只用于提供或改进本政策所述的用户可见功能及必要的安全与故障处理。

## 数据安全

正式服务使用 HTTPS 传输图片。生产后端必须明确图片是否落盘及日志保留期限；首版目标是不持久化保存原图，仅在完成分析所需的时间内处理。部署生产服务后，应在上架前把最终的数据保留规则写入本政策。

## 版权与授权

ArchBuddy 不绕过登录、付费墙或网站访问限制。用户应确保有权访问、保存和处理所选图片，并遵守来源网站条款和适用法律。
