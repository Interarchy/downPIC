## 可粘贴的审核员说明

本扩展的单一用途是将用户选定的参考图整理为图词素材，并使用明确发起的 AI 分析与统一云库支持后续设计创作。后台 API 返回数据，不向浏览器提供需要执行的远程代码。

建议审核流程：

1. 在普通 HTTPS 网页打开扩展弹窗，开启网页图片工具；用一张非私人测试图检验浮框、保存与图词库。
2. 点击“邮箱 / Google 登录或注册”，在 ArchBuddy 官网完成登录，并点击“连接此账户”；返回插件，确认显示账户和三项额度。身份认证需要使用原商店扩展 ID，随机解压生成的新 ID 不在服务端允许列表中。
3. 点击图片浮框的反推入口，确认侧栏立即打开并接收图片；此动作本身不会自动执行模型。
4. 阅读界面中的 AI 处理说明后发起一次可控简析或反推，查看返回结果及对应额度变化。新注册试用权益按当前官网规则提供，不要求先购买才能审查基本功能。
5. 在图词库与侧栏切换 EN / 中，确认相关界面同步；“打开 Canvas”在新标签页打开同一产品画布。
6. 专业云库需要有效专业版账户。若审核方需要完整测试该付费功能，应由发布负责人通过商店审核备注的私密渠道提供专用审核账户或安排测试资格；不得在 ZIP、公开仓库或公开商品描述写入密码和会话令牌。不要要求审核员用自己的银行卡付款。

请勿将图片下载、图库浏览与 AI 调用混为一项：普通下载免费，成功简析消耗简析次数，深度功能使用对应权益。账户与额度由服务器校验，界面只展示状态。

## 提交前检查

- [ ] 核对源码分支、完整提交 SHA、包版本、包 SHA-256 与文件清单。
- [ ] 两个 ZIP 都来自同一已核验源码；允许浏览器分发元信息不同，不允许 Edge 使用旧隐私页/旧运行脚本。
- [ ] 核对两个原商店条目及当前线上版本，不创建新身份替代更新。
- [ ] 更新商品中英文说明、单一用途、每项权限理由、数据用途与远程代码字段。
- [ ] 公开隐私页可访问，内容覆盖统一账户、所选素材 AI、任务结果保存、专业云库和第三方服务；与包内隐私页一致。
- [ ] 更新真实 0.7.5 截图：弹窗账户三项额度、网页浮框/侧栏、完整图词库、专业云库容量；使用合成素材和非私人示例资料。
- [ ] 原版用户升级前备份重要本地素材；确认升级无需卸载，旧素材不自动上传或归属首个登录账号。
