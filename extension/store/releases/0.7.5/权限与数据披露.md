# 0.7.5 权限与数据披露填写依据

日期：2026-10-30。Chrome 与 Edge 使用同一套业务数据流；以下是按本版实现准备的填写稿，不代表商店已接受或完成审核。隐私正文以本版 `privacy.html` 为准，提交时公开 URL 应与其范围一致。

## 单一用途

帮助设计师将选定的网页或本地参考图整理为图词素材，并通过提示词分析、优化、搜索和统一账户云库连接到后续 Canvas 创作。

## 两店共用的权限理由

| 清单权限 | 填写理由 |
| --- | --- |
| `activeTab` | 在用户主动选择图片并操作时访问当前标签页；直接读取所选图片失败时，可截取当前可见区域以裁取用户选择的图片。不会因浏览网页而自动上传整页截图。 |
| `scripting` | 图片工具开启时将包内脚本与样式注入已打开的普通网页，使保存和反推入口立即生效。 |
| `sidePanel` | 在当前网页旁展示参考图、提示词生成和优化界面。 |
| `downloads` | 用户主动保存图片到浏览器下载目录；读取相关下载记录以定位扩展保存的原图，并在用户确认后删除对应文件。 |
| `storage` | 保存界面语言、开关、用户同意状态、账户相关缓存与素材元数据；图片副本、预览、索引和插件会话使用扩展本地存储或 IndexedDB。 |
| `alarms` | 用户已开启图库 AI 时，恢复待处理的简析任务；实际请求仍须通过登录、用户同意和权益校验。定时唤醒本身不代表上传全部图库。 |
| `identity` | 使用浏览器授权窗口连接 ArchBuddy 官网的邮箱或 Google 登录，接收短期授权码并交换插件会话。不读取 Google 邮箱邮件，也不请求 Gmail 邮件权限。 |
| `http://*/*`、`https://*/*` | 在不同设计网站提供可关闭的图片浮框，读取用户选定图片与来源信息，并访问明确的 ArchBuddy HTTPS 服务及用户选择的图片资源。不是收集完整浏览历史，也不是任意远程代码执行。 |

## Chrome Privacy practices

1. 填写上述单一用途和各项权限理由。
2. **远程代码选择“否”**：浏览器执行脚本随安装包提供；服务端返回图片、文字或向量等业务数据，不将响应作为 JavaScript 或 WebAssembly 执行。调用远端 AI 接口不等于在扩展中执行远程代码。
3. 数据类别依据如下。即使只在本地保存，也应披露该处理；后台中文字段名称可能略有不同。

| 数据类别 | 本版填写依据 |
| --- | --- |
| 个人身份信息 | 是：统一账户邮箱、显示名称、账户标识与插件会话关联信息。旧稿“不收集邮箱”已不适用。 |
| 身份验证信息 | 是：短期授权码、插件会话及鉴权状态；扩展不单独收集密码，也不向网页浮框暴露会话凭据。 |
| 财务和付款信息 | 是：展示账户套餐、购买形成的权益、BuddyCoin 余额及有关状态；付款在官网/Waffo 完成，扩展不读取银行卡号。不能把“不收银行卡”写成完全不处理购买相关数据。 |
| 网络记录 / 网页浏览活动 | 是：用户选定图片的来源网页地址、相关标题与下载记录，用于来源回访和素材整理；不建立所有网页访问历史。来源网址在明确保存云素材时可上传，不发送给图片分析或向量模型。 |
| 用户活动 | 是：与用户主动操作有关的分析任务状态、额度与必要安全/运行记录；不收集键盘内容、鼠标轨迹或跨站广告画像。 |
| 网站内容 | 是：用户选择的图片、名称、描述、提示词、标签、语义查询及生成结果。 |
| 健康信息、个人通讯、位置 | 当前不作为专门功能采集；不读取 Gmail 邮件或地理定位。用户自填内容不应被描述成系统主动读取这些服务。 |

Limited Use 三项声明应按本版实际用途填写：不出售或转移数据用于与功能无关用途，不用于个性化广告，不用于信用评估或放贷。隐私正文、后台勾选与功能必须一致，不能保留旧版匿名/纯本地口径。

官方依据：[隐私字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)、[User Data FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)。本表是对具体代码行为的应用判断，不是 Google 对本插件的审核结论。

## Edge Privacy 页面

Partner Center 的字段不必与 Chrome 完全相同，但数据事实应相同：

- 本版访问、传输或保存账户信息与所选素材，不能声明“不处理个人信息”。
- 填写可公开访问的隐私 URL，明确收集、使用、披露、保留和删除方式。
- 权限及远程代码说明采用上表；如后台提供数据类别选项，按同一事实映射填写。
- 明示 AI 与专业云库需要账户及权益；付款通过官网完成。不要宣称所有功能永久免费、匿名可用或无需账户。
- Edge 旧的独立隐私页已不符合本版功能，不能只更新 ZIP 而保留旧的对外说明。

官方依据：[发布扩展及隐私页面](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)。

## 应公开说明的数据流与保留

| 数据 | 用途与位置 | 规则 |
| --- | --- | --- |
| 本地图片、预览、提示词与索引 | 本地图词库、分类、查看与搜索 | 保留至用户删除或浏览器清理；不因登录自动全量上传。旧数据保留为本机历史素材。 |
| 账户邮箱与会话 | 官网 Clerk 登录、统一账户服务与插件后台 | 插件退出撤销插件会话；不删除本地下载文件。 |
| 用户选择的 AI 输入 | ArchBuddy 服务转交对应模型 | 只处理所选功能所需图片或文本；图片分析使用 DeepSeek，文本向量使用腾讯云 TokenHub。 |
| 任务状态及完成结果 | 统一执行服务的幂等恢复与结算 | 请求状态、提示词/评估/简析/向量结果保留 30 天；原始请求图片不写入这些任务记录。 |
| 主动上传的专业云库图片及元数据 | 同一账户的私有云素材、Canvas 使用 | 5 GB/账户，原图与预览合计，单图 20 MiB。专业版有效期间保留；到期后 30 天只读供下载/续购，之后进入清理范围。 |
| 普通 Canvas 素材 | 画布上传和生成结果 | 采用独立的 30 天保留规则；不等同于专业云库长期保存。 |
| 订单/权益/安全记录 | 计费、故障处理及防滥用 | 不应笼统承诺所有账户和交易记录都会随图片在 30 天内删除；具体处理以官网条款及账户服务为准。 |

Clerk、Vercel、Cloudflare、腾讯云及相应模型处理方按功能参与服务；Waffo 处理官网付款。ArchBuddy 不使用用户图片或提示词训练自己的模型；这不代表各独立供应商具有相同的保留或训练政策，不作出未经证实的第三方保证。
