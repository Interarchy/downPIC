12浏览器扩展与本地图词库

本地素材

网页图片保存到浏览器下载目录；您主动保存图片时，采集当时的来源网页地址一并保存在扩展本地，供图库详情查看和打开，不发送给 AI 服务或统计系统。来源地址不写入图片文件；历史缺少来源的图片和本地导入图片不会自动查找或补全网址。图词库预览、导入图片副本、分类、已确认提示词及向量索引保存在扩展本地。导入文件夹会复制支持的图片，不移动电脑原文件；导入本身不会批量调用 AI。图片大图在图词库网页内查看，支持左右浏览和滚轮缩放。浏览器无法直接打开导入图片的原电脑文件夹，只能显示导入时记录的相对目录。项目跨分类拖动不移动电脑目录。

图片与提示词 AI 处理

开启图库 AI 后，新下载图片的限宽预览可经 ArchBuddy 服务发送给 DeepSeek，生成短视觉描述并保存到本地。主动生成旧图描述或完整提示词时才发送所选图片或预览；效果优化只在点击评估时发送选定生成图及当前提示词。AI 处理经统一账号服务鉴权并按服务器权益记录结算。为避免网络中断后重复调用或扣费，统一服务保存请求状态与已完成的反推、评估、描述或向量结果 30 天，原始请求图片不写入这些任务记录。您主动保存到云素材的图片与提示词按下述云端规则保存。

自然语言搜索

您另行确认向量处理后，图片名称、分类、视觉描述和词库提示词文本在建立或更新索引时，经 ArchBuddy 服务发送给腾讯云 TokenHub 生成文本向量；提交搜索时发送本次查询生成一次向量。输入中的关键词匹配、向量保存与比对、结果合并在本地完成。图片字节、文件路径和来源网址不发送给 TokenHub。关闭图库 AI 后停止新模型请求；已有本地素材仍可浏览。

本地保存与删除

侧栏仅展示最近五份已确认提示词，图词库保留全部已确认方案，直到用户删除或浏览器清理。删除图库记录与删除下载原图是不同操作，由用户确认。清除扩展数据或卸载扩展可能使图库、提示词和向量索引丢失；已下载原图不随卸载自动删除。本地素材不自动跨设备同步。

统一账号与安全

官网、Canvas 与插件使用同一个 ArchBuddy 账号。插件通过官网的邮箱或 Google 登录页完成授权，不单独收集密码或手机号。短时授权码使用 PKCE 交换插件会话，登录凭据保存在扩展后台的 IndexedDB，不发送给网页内容脚本。BuddyCoin、简析和深度反推权益以服务端账户账本为准，普通文件下载免费；模型密钥仅保存在服务器。插件退出会撤销本插件会话，不会删除电脑上的下载文件。

云素材与本机历史

新版本按账号隔离本机素材和检索缓存。升级前的素材保留为“本机历史素材”，不会自动属于第一个登录账号，也不会自动上传。您在云素材页选择具体项目并点击保存时，才将名称、提示词、标签、来源网址写入当前账户。图片须另外勾选上传；只有本地预览时明确标注为预览副本，不称为原图。

主动保存到专业版云图词库的素材可由同一账号在 Canvas 使用。专业版每账户提供 5 GB 云库空间，原图与预览合计计入容量，单张图片最多 20 MiB；有效期内持续保留。套餐到期后保留 30 天供下载或续购，期间只读，不能新增上传；宽限期结束后进入清理范围。普通 Canvas 上传图和生成结果另按 30 天规则保留。仍被画布项目引用的图片，在移除云库条目后可能继续保存并占用容量。本地下载文件不受云端删除影响。账户注销与隐私事项可通过官网账户服务及支持渠道办理。退出或切换账号后隐藏原账号缓存；同一操作系统用户仍可能通过浏览器开发工具访问本机文件，请勿共用不可信的浏览器配置。

我们不出售数据，不用于个性化广告、信用评估或跨站画像；Chrome 分发版本遵循 Chrome Web Store Limited Use 要求。插件一般使用支持可联系 melyyanggg@gmail.com；本政策的数据权利、隐私与法律联系仍为 melyyang@163.com。

Browser extensions and local library

Local materials

Web images are saved to your browser downloads folder. When you choose to save an image, its source page URL at the time of capture is also stored locally in the extension, so you can view and open it in the library details. The URL is not sent to AI services or analytics systems and is not embedded in the image file. Missing source URLs are not automatically looked up or filled in for historical or locally imported images. Library previews, copies of imported images, categories, confirmed prompts and vector indexes are stored locally in the extension. Importing a folder copies supported images without moving the original files; importing alone does not make batch AI calls. Full-size images can be viewed in the library page, with previous/next navigation and mouse-wheel zoom. The browser cannot directly open an imported image's original folder on your computer; it can only show the relative folder recorded at import. Moving projects between categories does not move folders on your computer.

AI processing of images and prompts

After you enable Library AI, width-limited previews of newly downloaded images may be sent through ArchBuddy to DeepSeek to generate short visual descriptions saved locally. Selected images or previews are sent for older-image descriptions or full prompts only when you request them. Result refinement sends the selected generated image and current prompt only when you click Evaluate. AI processing is authenticated through the shared account service and settled against the server's entitlement records. To prevent duplicate calls or charges after network interruptions, the shared service retains request statuses and completed prompt extraction, evaluation, description or vector results for 30 days. Original request images are not written to these task records. Images and prompts you choose to save to the cloud library are retained under the cloud rules below.

Natural-language search

After you separately consent to vector processing, image names, categories, visual descriptions and library prompt text are sent through ArchBuddy to Tencent Cloud TokenHub to generate text embeddings when building or updating the index. Submitting a search sends that query to generate one embedding. Keyword matching, vector storage and comparison, and result merging take place locally. Image bytes, file paths and source URLs are not sent to TokenHub. Turning off Library AI stops new model requests; existing local materials remain available to browse.

Local storage and deletion

The sidebar shows only the five most recent confirmed prompts. The library keeps all confirmed versions until you delete them or the browser clears them. Deleting a library record and deleting the downloaded original image are separate actions that you confirm. Clearing extension data or uninstalling the extension may remove the library, prompts and vector indexes. Downloaded original images are not automatically deleted when the extension is uninstalled. Local materials do not automatically sync across devices.

Shared account and security

The website, Canvas and extension use the same ArchBuddy account. The extension is authorized through the website's email or Google sign-in page and does not separately collect passwords or phone numbers. A short-lived authorization code is exchanged for an extension session using PKCE. Login credentials are kept in the extension background's IndexedDB and are not sent to webpage content scripts. BuddyCoin, brief-analysis and deep-reverse entitlements follow the server-side account ledger. Ordinary file downloads are free. Model API keys are kept only on the server. Signing out of the extension revokes its session without deleting downloaded files on your computer.

Cloud library and local history

The new version separates local materials and search caches by account. Materials from before the upgrade remain as local historical materials; they are not automatically assigned to the first account that signs in or uploaded. Names, prompts, tags and source URLs are saved to the current account only when you select specific items on the cloud library page and click Save. Uploading images requires a separate selection. When only a local preview is available, it is explicitly labeled as a preview copy, not an original image.

Materials explicitly saved to the Pro cloud library can be used in Canvas with the same account. The Pro plan includes 5 GB of cloud-library storage per account; original images and previews share this quota, with a maximum of 20 MiB per image. Saved library images are retained while the plan is active. After expiry, they remain read-only for 30 days for download or renewal; new uploads are unavailable. After this grace period they are eligible for deletion. Ordinary Canvas uploads and generated images follow the separate 30-day retention rule. A library image still referenced by a Canvas project may remain stored and counted after its library entry is removed. Cloud deletion does not delete locally downloaded files.
