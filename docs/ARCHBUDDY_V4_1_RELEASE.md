# ArchBuddy V4.1 版本记录

确认日期：2026-10-08。用户将本轮修改定义为 V4.1，并授权提交和推送 GitHub。

## 版本与发布边界

- 产品版本：V4.1。
- 扩展数字版本：0.6.1，由 V4 的 0.6.0 递增；manifest.version_name 显示 V4.1，仍使用 Manifest V3。
- 分支：direction/plugin；远端：origin（Interarchy/downPIC）；版本标签：archbuddy-v4.1。
- 本轮交付为本地实现与 GitHub 源码版本。没有部署 CloudBase、更新商店或发布 GitHub Release。

## 核心用户路径

浏览网页 → 浮框选分类保存参考图 → 图词库整理素材并回访来源网页 → 侧栏生成与优化提示词 → 确认后沉淀到词库。

## 本轮变化

1. 保存图片时保留采集网页地址，详情元信息依次显示来源网页、保存时间；去掉项目、分类及复制链接按钮，直接点击来源回访。
2. 修复下载尚未完成时自动描述误判失败、后台队列忙时遗漏完成通知；待下载完成再生成，并保持扩展归属、目录和 AI 同意校验。
3. 浮框删除“分类”冗余文字，缩窄操作按钮，右侧 Lucide chevron 收起为小 Logo 与“展开”。展开及收起状态点击 Logo 均直达图词库；展开文字单独恢复浮框。
4. 浏览器 Logo 菜单仅提供打开图词库、打开侧边栏两个功能入口，总开关保留。
5. 侧栏图词库、提示词生成、提示词优化均为纯文字；图词库直接新开完整页面，关闭再打开侧栏保留任务阶段与草稿。
6. 分类管理集中在图库左栏，新增输入位于图库/词库下、全部图片上，去掉独立标签。分类提供改名、删除及项目跨分类拖动；非空分类先移走项目，删除分类不隐式删除图片，兼容旧分类与别名。
7. 提示词生成去掉最多三张说明行，将清空参考图按钮与第一张参考图标题并排；Gemini、ChatGPT 外链使用 Lucide external-link。
8. 修复新增分类输入聚焦边框被裁切；新增分类时清空旧搜索与详情。

## 验证依据

本轮开发已运行现有19项扩展检查及相关静态语法、HTML引用/ID与差异格式检查；没有新增测试框架。隔离真实Chrome验证来源持久化与回访、浮框收起/展开/Logo入口、图库分类及历史项目移动、侧栏直达与阶段恢复、紧凑布局和焦点边框。桌面与窄屏截图已目视，定向验证脚本异常0。诊断还用原业务函数复现下载状态与队列时序缺陷；真实商店现场的唯一原因尚未确认。

开发与验收记录：[来源网页](../specs/003-local-asset-library/source-page-2026-10-08.md)、[下载描述诊断](../specs/003-local-asset-library/download-attribution-2026-10-08.md)、[交互修订](../specs/003-local-asset-library/navigation-2026-10-08.md)。三个静态候选及独立验收记录随本次提交保留；最终实现验证的隔离浏览器配置、下载与临时证据在忽略目录 extension/dist，未进入Git。

## 已知限制与下一步

- 商店安装不会自动获得本轮源码；真实商店版本升级、CloudBase部署和上架审核须后续安排。
- 旧失败描述不自动批量重新上传，可在同安装内手动生成或重新保存图片；历史缺来源地址不推断补齐。
- 本轮没有重新运行真实模型端到端验收；浏览器定向验证拒绝外部模型请求，来源回访可用本地模拟响应验证导航。
- 分类与素材只在本机扩展内管理，卸载或清除浏览器资料仍可能丢失；本轮未增加云同步或统计采集。
- 本地体验：重新加载仓库 extension 目录的扩展，再刷新网页、图词库与侧栏。

版本字段依据：[Chrome manifest版本规则](https://developer.chrome.com/docs/extensions/reference/manifest/version)与[version_name说明](https://developer.chrome.com/docs/extensions/reference/manifest)。
