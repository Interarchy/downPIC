# ArchBuddy 首屏三种方向

## 目标

保留绿色品牌背景，让首屏占满一个视口，下滑后进入四段创作演示。首屏用逐字出现的 ArchBuddy 与轮换文案表达产品价值，在文字下方以可抽取的四张工具卡介绍完整设计链路。

## 比较入口

- A：`/hero-options.html?v=a`，深绿悬浮工具匣。居中品牌字、柔和景深与实体盒沿，悬停时单卡上提。侧重品牌识别和抽取的直观关系。
- B：`/hero-options.html?v=b`，浅绿建筑档案匣。左对齐大字、纸感档案卡与抽屉，卡片向上抽出。侧重建筑设计气质和个人积累。
- C：`/hero-options.html?v=c`，光轨工作台。近黑森林绿、细光轨与透明模块，悬停模块向上提取并横向展开。侧重创作工具的科技感。

比较页上方可以即时切换三版，并带 noindex。用户已选择 C；正式首页采用 C 方案，移除比较控件。

## 文案

A 轮换：让灵感，成为设计的起点；让参考，成为清晰的语言；让每次创作，都有所积累。

B 轮换：收藏所见，构筑所想；让参考图，说出设计意图；让每一次推敲，都有迹可循。

C 轮换：从一张参考，到新的可能；把设计意图，连接成画布；让创作循环，持续向前。

四张卡片共同介绍快速采集、构建提示词、画布创作、搜索复用。卡片描述功能本身，不宣称两端素材自动同步或统一账号额度已经上线。

## 交互与性能

- 桌面悬停抽卡并显示详细说明，移向其他卡片可连续浏览；键盘聚焦和点击也可展开。
- 手机点按卡片，上方卡片抽出，下方显示对应详细介绍。
- 标题逐字打印，句子停留后擦除并轮换；离开首屏或切到后台时暂停，减少无效运行。系统减少动效偏好下直接展示完整文字。
- 只使用本地CSS、JavaScript、品牌图标与现有Lucide图标，不增加大图、视频或外部字体请求。
- 首屏之后复用已完成的四段演示，维持首章先显示、后续章节按需准备的策略。

## 已验证

脚本语法解析、唯一id、三种桌面首屏边界、手机首屏边界、横向溢出、抽卡说明、鼠标/聚焦状态与手机说明区域。隔离浏览器采样的脚本错误为0。用户实际设备上的交互偏好仍以最终选择为准。


## 2026-10-23：方案 C 正式首屏与全站森林绿统一

- 按用户选择，将 C 方案作为正式官网首屏，保留全屏高度，下滑进入四段演示；移除比较页切换控件和“四项核心能力”说明。
- 工具台底座文案采用“从参考到创作，让设计一路向前”。四卡以图片、提示词、效果图、图词为主标题，分别配快速采集、构建优化、画布创作、搜索复用；悬停与键盘聚焦进一步放大操作对象。
- 全站外层背景及四段演示统一为 #071e18 近黑森林绿，调整下方功能与分析区域的文字、面板及边框对比度；真实产品界面内部保持原样。
- 同步比较页 C，保留 A/B 供历史比较。沿用分段按需加载，不增加大图、视频或远程字体。
- 验证：JavaScript 语法通过；正式首页无重复 id；四段主题链接已更新；桌面与手机首屏均占满视口且无横向溢出，悬停关键词放大和详情展示正常；11 个主要页面区域背景一致，浏览器脚本错误为 0；概念图面板已统一深绿并检查文字可读性。
