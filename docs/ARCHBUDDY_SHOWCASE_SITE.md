## 当前目标与阅读路径

产品定位 → 01方案创作中的断点 → 02工作链路与产品机会 → 03我们的产品思路 → 04三大功能 → 插件/图片测试集下载与安装。页面连续下滑可读，历史五页链接保留，不是当前首页必须跳转的阅读路径。

两条业务链路：

1. **方案创作**：采集参考图 → 设计师推进方案 → 沉淀参考图库 → 找回与复用到下一轮采集。
2. **AI效果图迭代**：收集参考图 → 反推提示词 → 外部工具生成AI效果图 → 迭代提示词 → 沉淀提示词库 → 复用图词回到参考入口；生成/迭代另有双向小循环。五个步骤完整呈现，ArchBuddy只在采集、反推、迭代和沉淀四处介入。

三大功能支撑：采集参考图、反推与迭代提示词、沉淀图词资产。前两项在功能区上方并列，资产区在下方承接产出，通过找回与复用支持两个功能；不把资产管理误当第三个业务场景。

这是对已有能力的产品叙事与视觉调整，不新增插件生图、自动设计方案、云同步或登录。网页展示演示截图与下载，不读取访客图库或调用模型。
