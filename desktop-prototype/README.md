# 桌面端低保真交互原型

本轮覆盖：

- 桌面端全局框架
- 首页与自动聚焦的自然语言搜索
- 历史搜索和关键词建议
- 按项目、按关键词标签及组合 AND 筛选
- 新增个人关键词标签并选择专业分类
- 将任意关键词标签拖到其他分类，并支持撤销
- 搜索结果瀑布流、匹配原因和无结果恢复
- 图片详情中的描述与关键词编辑
- 通过同一输入框搜索并复用全素材库已有关键词，或创建新关键词
- AI / 人工关键词以冷暖色系区分、自动保存与最多 50 步连续撤销
- 人工修正后的描述与关键词立即进入搜索
- 图片来源网站、网页标题、网址、采集时间和打开入口
- 完整未解析工作页：统一实时计数、状态概览、状态筛选、失败原因、单张和批量重试
- 三步首次启动流程：创建、连接或移动素材库，目录权限检查、错误恢复和两级目录确认
- 详情头图原图查看器：关闭按钮与图片对齐，支持全屏预览、独立关闭和 Esc 返回
- 读取插件管理目录中的真实图片与来源信息；真实索引可用时自动替换演示数据
- 首页、项目树与未解析页使用同一份真实素材状态，避免数量口径漂移

## 启动

在项目根目录运行本地素材服务（推荐）：

~~~powershell
node spikes/phase1-analysis/server.mjs
~~~

然后打开 `http://127.0.0.1:4174/desktop-prototype/`。

该服务每次打开页面都会扫描插件素材目录，因此保存新图片后刷新桌面端即可看到。Python 静态服务仍可用于纯 UI 回退，但不会自动扫描新图片。

## 测试

~~~powershell
node --test desktop-prototype/tests/*.test.mjs
~~~

推荐验证：

1. 打开页面后直接输入，无需先点击搜索框。
2. 输入“有柔和天光的混凝土展览空间”并按 Enter。
3. 从左侧选择“文化建筑”和“清水混凝土”，再提交“带庭院的木结构学校”，确认旧筛选自动清除；随后点击“木构”，确认它作为结果后的主动精筛生效。
4. 点击任意搜索结果，在右侧修改描述、删除关键词；从库内候选直接添加“庭院”，再创建新关键词，确认自动保存与撤销。
5. 搜索“海边的彩色充气膜结构”，确认出现可恢复的无结果页面。
6. 点击“按关键词标签”右侧加号，新增“悬浮屋顶”，确认空格和重名校验有效。
7. 将“形态”中的“山地”拖到“空间”，确认图片关联与搜索结果不变，并测试撤销。
8. 新增图片关键词“框景”，关闭详情后搜索“框景”，确认目标图片成为唯一结果。
9. 滚动到详情底部，确认来源网站、网页标题、网址与采集时间可见，且“打开来源网站”指向该网址。
10. 点击标签正文确认不会删除；连续删除三个标签后，确认撤销按钮显示步数并能逐步恢复。
11. 点击左侧“未解析”，确认导航、首页和页面总数均为 4；筛选失败任务并执行单张或批量重试，确认失败数变为 0、等待数变为 3，总待处理数仍为 4。
12. 打开 `?flow=onboarding`：先选择受保护目录确认无法继续，再选择推荐目录，检查三项权限、两级目录预览并完成进入首页。
13. 打开任意图片详情，确认“×”与头图右上角对齐；点击“查看原图”进入全屏预览，再用 Esc 返回详情。
