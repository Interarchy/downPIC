# V3 侧栏操作流程修订

日期：2026-09-22。依据：用户人工体验后的整体修改要求。本文件对既有 V2/V3 文档中冲突的交互描述优先适用；数据隔离、安全与本地开发边界继续有效。

## 提示词构建

> 2026-09-24 补充：三张参考图可同时开始分析，分别显示等待时间与错误。整体 Prompt 大框改为按段编辑：标题用于对应维度，正文及整体生成准则均可修改；替换仅更新对应段落，其他手动修改保留。修改同步到已选参考图的编辑框，确认后保存修改后的完整版本。

1. 默认展示参考图一。选择、粘贴或拖入图片后，点击该图的“开始分析”。
2. 结构化提示词直接在该图下方呈现，每个有内容的维度都有可完整阅读、直接编辑的文本框。
3. 未采用的维度显示“加入”；整体预览已有同一维度时显示“替换”。已采用的维度显示“移除”。最终每个维度只保留一份选用内容。
4. 已采用维度继续编辑时，整体预览同步更新。分析其他图片不改写已选内容；重新分析同图时保留已采用的编辑内容。
5. 用户按需添加参考图二、三，最多三张。三张图各自保留图片、分析结果和编辑状态；聚焦某张图片后粘贴会写入该图。
6. 底部只保留名称、加高后的整体 Prompt 预览、“整体确认”和“复制”，移除重复的“当前方案”编辑区。
7. 图片分析及模块编辑只形成编辑会话。点击“整体确认”后才保存到“最近确认的提示词库”，最多五份。超限先明确确认移出最旧记录。
8. 确认成功后解锁复制；任何影响已选内容或名称的修改会再次要求确认。复制只复制已经确认的文本，不再创建版本。

## 效果优化

> 2026-09-24 补充：符合为绿色 #23734c，部分符合为黄色 #a87800，明显偏差为红色 #bd302b，无法判断为灰色 #68736c。这是用户明确指定的墨绿主题例外。

1. 最上方先放生成效果图，支持粘贴、拖入与文件选择。
2. 下方通过紧凑下拉框选择最近确认的基本提示词；原文折叠查看，不默认展开长篇文字。
3. 保留明确的发送确认，点击“开始评估”才发送生成图与选定版本的可观察维度。
4. 不展示来源图、来源修复入口和重复的方案列表。
5. 评估结果按维度给出“符合／部分符合／明显偏差／无法判断”和简短差异提醒；不伪造百分比精度或评分。
6. 每个结果卡片只有一份可编辑原提示词。模型调整提示折叠展示供参考，不另设建议编辑区或修改草稿区。
7. 在原文直接编辑，点击“确认修改”保存版本后再复制。未修改时不重复建版。参考图缺失不阻止这一步的文字版本确认，保留原有来源元数据状态。
8. 每份保留最近五个版本；轻量侧栏不再展开版本时间线。已保存历史数据继续兼容保留。

## 数据和实现约定

- 编辑会话元数据固定使用 `archbuddyBuilderV3`；三张参考图字节暂存在扩展自身 IndexedDB，以明确的编辑方案 UUID 分区，避免三张图片挤占会话存储。
- “重新构建”需确认。未入库的当前编辑方案图片按其 UUID 清理，已确认库记录保留。
- 保留来源图片关联供未来本地网页素材库使用，不在效果优化中额外要求用户选择或上传来源图片。
- 仅采用的来源图写入版本关联。保存失败时不解锁复制，不把未确认编辑冒充为已入库。
- 新版本来源使用 `initial-confirm/revision-confirm`，旧版 `initial-copy/revision-copy/legacy-baseline` 继续读取。
- 修复原“加入／替换”被旧版本快照覆盖的问题：构建会话与只读版本分开，确认时生成快照，构建过程不经过旧版 `draft.save`。
- 复用现有 AI 路由和匿名认证；不新增模型调用、权限或云端资源。默认本地模式继续生效，正式打包必须恢复 cloud。
- UI 沿用现有白底与墨绿：`#f7f8f7`、`#ffffff`、`#24332d`、`#25634b`、`#194a38`、`#dce3de`；微软雅黑体系，正文 14px，左对齐，各参考图按纵向阅读顺序排布。

## 验收重点

- 连续发起 A、B、C 三图分析，各有独立进度；任一完成或失败不结束其他请求。
- 在最终框手动修改材料和光线，再用另一图替换材料，光线文字应保留；确认复制与入库文字一致。
- 手动修改整体生成准则，确认后进入效果优化，后续确认版本仍保留修改后的准则。
- 本地启动脚本显式设置并发容量为 3；未来发布时核对云端是否仍显式配置 ARCHBUDDY_MAX_CONCURRENT=1。本地改动不会自动更新云配置。

- A 图加入“材料”，B 图替换“材料”，整体预览只出现 B 的材料；编辑 B 材料后预览实时变化。
- A、B、C 分别分析后结果互不覆盖，第四张入口不出现。
- 未确认不能复制，未确认内容不出现在提示词库；确认后出现，继续改动再次禁用复制。
- 效果图可在选提示词之前上传；选择提示词后保留已上传图片。
- 评估结果内直接编辑并确认，提示词库更新，复制所得为已确认版本。
- 旧确认记录可继续用于评估，来源缺失不阻碍文字优化。
- 静态检查以本次 verification.md 记录为准；真实 Chrome、真实模型链路需由用户继续人工体验确认。
