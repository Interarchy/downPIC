# 手机号登录与积分账户规格

**日期**：2026-10-09
**分支**：`codex/phone-login-credits`
**状态**：用户已确认产品规则；本地模拟闭环实现与验收通过，未接真实短信/模型/支付，未部署、未上架。

## 目标与核心路径

让首批真实使用者未来能够拥有稳定的 AI 使用身份、看懂消耗并管理积分，为后续收费准备可核对的账户记录。本轮先把流程在本地跑通，不把模拟验证码、演示模型或占位价格描述为已可商业运营。

核心路径：浏览与采集本地素材 → 在 AI 操作前登录 → 首次获赠 200 积分 → 查看本次消耗 → 成功分析并扣分 → 查看余额与明细 → 提交产品反馈申请追加，或查看积分包并提交待处理申请。

## 用户确认的权益与计费口径

| 项目 | 规则 |
| --- | --- |
| 登录 | 手机号验证码优先；首次验证自动创建账号；本轮为明确标识的本地开发验证码 |
| 注册赠送 | 每账号一次性 200 积分，不设到期，不每日恢复 |
| 反推提示词 | 每张成功分析的图片 1 积分；2 张 2 积分，3 张 3 积分 |
| 提示词优化 | 每张成功评估的图片 1 积分 |
| 核心视觉特点 | 每张成功生成 0.1 积分，包括用户已同意的保存后自动生成 |
| 向量建索引与搜索 | 不扣用户积分；模型调用仍受调用次数和频率保护 |
| 个人每日保护 | 北京时间自然日最多 50 次模型调用尝试 |
| 项目每日保护 | 全部账号共享北京时间自然日最多 500 次模型调用尝试 |
| 产品反馈赠送 | 站内提交产品反馈，由管理员审核；每账号只能申请一次，通过后赠送 200 积分 |
| 积分包 | 100 / 500 / 1000 积分，¥1 / ¥2 / ¥3 仅为占位价格；不接支付，申请不自动到账 |

积分衡量用户权益，调用次数控制平台成本，两者分开。例如生成 100 张核心视觉特点合计 10 积分，但需要 100 次模型调用，按个人每日 50 次保护，至少跨两天完成；期间其他 AI 调用也占用当天次数。积分余额不足与当天调用达到上限应分别解释。

原“商店评分评价后赠分”方案已由用户确认改为站内产品反馈审核。不得要求评分、指定星级、评价截图或评论链接；产品反馈申请不跳转商店，也不自动授予奖励。每个账号仅一次申请，拒绝后不能重提；重复审核不能突破一次批准上限。

## 行为与数据要求

1. 未登录仍可采集、下载、分类、浏览和编辑本地内容。AI 操作需登录并保留原有 AI 处理同意。
2. 点击开始反推或开始分析前，在按钮附近展示本次预计消耗；多图按当前实际待分析数量计算。单张重新分析也提示 1 积分。自动描述开关明确 0.1 积分/张。
3. 账号页显示脱敏手机号、可用积分、积分来源和收支明细；退出再登录、服务重启不能重新赠送或清空余额。
4. 金额不由前端决定。服务端固定分项价格，用 0.1 积分作为整数存储单位：200 积分为 2000 单位，1 积分为 10 单位。
5. 调用前校验身份、积分、调用次数并预占；成功结算。确认失败释放积分，已开始的模型调用仍占每日次数。中断状态不得无证据宣称成功或重复扣分。
6. 每个业务请求有幂等标识；重复提交、重复批准或重复结算不能重复赠送/扣除。重试结果与处理状态明确可见。
7. 本地服务持久化账号、会话、收支和赠送记录；业务归属固定 `archbuddy/local`，客户端不能选择项目、阶段、余额或任意账号。
8. 积分包展示价格和申请状态；待处理订单不能直接转换为已付款。管理员操作必须可追溯，普通用户不能调用管理权限。
9. 切换/退出账号暂停自动 AI 队列并撤回本轮自动处理同意；进行中的扣分任务先完成或明确处理完后再切换，不将旧账号任务扣到新账号。
10. 登录只建立 AI 身份。图库继续属于当前浏览器的扩展本地空间；同一浏览器切换账号共用图库，退出不删除素材，不承诺私人账号图库或跨设备同步。

## 本轮范围与边界

包含账号入口、验证码登录、余额与流水、分项积分结算、一次反馈审核、占位积分包申请，以及最小本地管理员操作。复用 V4.1 的页面、AI 接口和本地素材模型，不引入会员等级、订阅系统、通用支付平台或新前端框架。

本地构建输出到 `extension/dist/local-account`，单独加载以免把测试凭据和回环地址混入规范源码的云运行配置。本地后端只监听回环地址，默认演示验证码和演示 AI，不能被误认为已联通真实手机号或真实模型。

范围外：CloudBase 资源创建/部署、商店更新、真实短信、真实支付、微信登录、匿名用户迁移、云图库、跨端同步和生产化运行保障。未来发布前须分别确认供应商条件、隐私披露、持久化与权限、匿名入口过渡，以及项目 500 次保护对付费体验的影响。

- 本地演示：首次注册 200 分；重复登录不重复送；1 / 2 / 3 图显示 1 / 2 / 3 分；核心视觉特点扣 0.1 分；确认失败返还；重启保留；用户仅看自己的流水；反馈重复批准不重复送；积分包申请不自动到账。
