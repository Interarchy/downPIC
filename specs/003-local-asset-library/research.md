# V4 技术决策记录

## 决策 1：以已确认方案作为首版素材边界

理由：V3 已有稳定的方案、来源图和版本关联，图像只保存一份。直接读取可以演示“资产找回与复用”，避免在本阶段建立第二套图片仓库。仅下载、未确认的图片暂不入库。

## 决策 2：元数据随原实体保存

方案增加 projectName、category；来源图引用增加 tags。读旧数据时字段缺省为空，修改仅写入被明确选中的方案。避免独立索引、同步和批量迁移。

## 决策 3：继续使用通过现有侧栏工作流

页面只设置用户明确选择的方案交接状态并打开侧栏；继续构建沿用既有来源图 ID 和方案 ID。页面不发起 AI 请求，也不复制 Blob。

## 决策 4：容量呈现区分已知与估算

已知来源图个数及字节数由本地记录计算。浏览器占用和配额来自浏览器估算，明确标为估算；不可用则显示“暂不可估算”。不申请 unlimitedStorage。

## 决策 5：保留现有删除边界

方案删除继续调用已存在的确认式删除路径，按方案 ID 清理来源图与会话工作稿。不提供单张来源图删除，避免破坏 Prompt 版本引用。
