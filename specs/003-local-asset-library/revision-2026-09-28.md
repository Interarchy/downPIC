# 2026-09-28 图库语义检索与图片工作流修订

## 目标与核心路径

下载图片 → 自动保存本地预览 → 自动生成并保存简短视觉描述 → 按自然语言含义检索 → 双击原图或生成完整提示词。

用户称当前产品为 V6；现有 manifest 为 0.6.0，历史开发文档仍归档在 003-local-asset-library。本轮先本地验收，不据此宣称商店版本已更新。

## 产品决策

- 搜索改为模型逐条判断查询与候选描述的语义相关性，支持改写、空间关系和否定条件。没有关键词预筛；点击搜索或回车提交，不随输入每个字调用。图库与词库各检索当前板块全部资产；词库分类筛选继续生效。
- 不引入新的向量服务或云端素材存储。复用 ArchBuddy 服务中的现有模型适配器；每批最多 24 条、单条最多 6000 字，检索完成后合并排序。页面内按查询和候选正文缓存最多 40 个批次；编辑后再次搜索会使用新正文。失败明确显示未完成，不混入关键词兜底结果。
- 新下载图片在用户开启图库 AI 后自动生成短描述，生成成功直接存入原图片记录。先前的下载不批量回传；无描述的旧图可手工填写，或生成完整提示词后复用摘要。描述编辑后自动保存。
- 自动描述使用单独短描述接口，串行队列持久化 pending / processing / ready / failed。限流延后处理；不对模型已可能计费但结果未知的中断请求盲目重试。关闭图库 AI 后停止新请求，不影响下载和本地数据。
- 下载、分析、语义检索均保持既有身份和额度约束。自动描述与每个语义批次各算一次模型调用，共用原有 20/200 每日限额；不新增预算空间。本地服务仍是进程测试额度，不声称已验证云端每日额度运行。
- 图库与词库图片均提供生成完整提示词入口，图片送入现有侧栏构建流程。空白构建自动填入完整模块；已有编辑内容优先添加参考图，满三张时确认后才重新构建。
- 单击查看详情，双击采集图片直接调用系统打开下载原图；词库来源图双击打开本地大图。采集图片角落显示小删除图标，保留删除确认；详情只保留生成完整提示词和打开原文件夹。
- 左导航用图库／词库与精简图标，宽度缩至 216px。项目类型支持拖动、插入标记及位置过渡动画，排序与侧栏共用原存储字段。
- 侧栏品牌表头与三栏导航整体固定，选中为统一绿色。提示词优化顶部新增 Gemini、ChatGPT 官网链接，图标保存于扩展内。

## 数据与服务边界

- 新增本地授权字段 asset_ai_consent_v1；旧版单次图片分析同意不自动视为后台下载描述同意。首用说明、图库开启入口、弹窗启用入口与侧栏关闭入口保持一致。
- 搜索仅发送当前板块候选名称、分类、视觉描述或提示词及查询；不发送原图字节、文件路径、来源网址。自动描述发送单张限宽预览。服务不记录请求正文。
- 新接口 /api/library/search 和 /api/library/describe 复用匿名鉴权、暂停开关、并发/速率上限、请求标识与既有 quota.reserve/finish。新增 alarms 权限用于描述队列唤醒。
- 本轮只修改本地 API 源码并重启本地服务，不创建或修改 CloudBase 资源；归属仍为 archbuddy / development / archbuddy-api。后续部署需同步新服务、商店权限说明和公开隐私政策，旧云端版本不能提供新接口。
