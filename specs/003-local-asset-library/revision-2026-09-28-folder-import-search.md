# 2026-09-28 图库本地文件夹导入与双阶段搜索

## 目标与决策

- 从插件侧栏及完整图词库都能导入用户主动选择的本地文件夹。所选文件夹是一级项目类型；下层文件夹是二级项目名称；直接放在一级目录下的图片归入“未分类项目”。同名一级类型合并展示，不重命名或移动电脑原目录。
- 图片完整副本写入扩展 IndexedDB，结构化索引写入 chrome.storage.local。允许 PNG/JPEG/WebP、单张不超过 10 MB；重复导入以相对路径、字节大小及修改时间跳过。失败和跳过给出数量，电脑原文件一直保留。
- 左侧项目行与右侧项目缩略卡都可拖到其他一级类型。项目中的全部图库图片统一修改虚拟分类；目标有同名项目时自然合并图片列表。下载目录及导入源目录均不移动。
- 输入搜索文字时立即在当前板块全量素材中做本地关键词匹配；回车或点击搜索才发送查询和候选文字到既有 AI 服务，按关键词结果优先、语义结果补充的方式去重合并。语义失败保留关键词结果并提示原因。快速连续改写查询时，旧结果失效，新提交排队至当前请求结束。

## 产品与安全边界

本地文件夹导入不触发批量图片描述，避免一次导入大量图片消耗个人 20 次、项目 200 次日额度。导入图片可在详情编辑并自动保存视觉描述，也可主动“生成完整提示词”。没有描述的导入图只有项目、文件名等元数据供语义检索，视觉内容召回仍取决于后续描述质量。删除导入图片/项目只清理扩展副本；混合项目可选择同时删除其中的下载原图，但导入源文件不受影响。

本轮未新增浏览器权限，也未改 CloudBase 云端资源、身份、日志、密钥、统计或预算；既有 `/api/library/search` 契约继续使用。全部修改保持本地，未部署和未更新商店。后续发布前需同步公开隐私说明，并用真实项目文件夹验证容量、导入时长、语义质量及跨类型整理体验。
