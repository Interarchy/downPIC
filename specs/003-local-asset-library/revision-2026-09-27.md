# V4 第四轮修订：可检索的图词资产库

## 核心路径与范围

1. 用户整理项目类型：重命名、拖动排序，侧栏与网页采集分类一致；历史下载物理路径保留，图库通过名称映射显示新分类。
2. 点击采集图片，在右侧查看详情，生成或编辑一段核心视觉描述并本地保存；复用既有图片分析及每日额度，不新增云端接口、持久化资源或后台扫描。
3. 两个素材页面顶部提供本地自然语言模糊检索，使用分词、建筑常用同义词、描述及 Prompt 匹配排序；不是向量模型，不声称能理解未描述的图像内容。查询搜索当前素材板块全部项目/分组；清空后回到所选目录。
4. 侧栏最近五份仅为展示限制；全部确认方案及版本持续本地保存，容量失败明确报错，不自动淘汰。旧版已经淘汰的记录无法恢复。
5. 图片可通过系统默认程序打开原图。删除可选仅移出图库或同时删除下载原图；整组删除只针对图库登记的图片，不波及目录内其他文件。Chrome 下载 API 不删除电脑上的空文件夹，界面须准确说明。无需桌面程序。
6. 弹窗和三栏命名按本轮用户原文调整；移除评估勾选框，将点击“开始评估”作为明确发起动作，保留按钮 title 与首次隐私说明中的发送对象。

## 界面方案

沿用既有绿色设计：主绿 #25634b、深绿 #174735、纸白 #f5f7f3、白色 #ffffff、正文 #243a2b、灰绿 #64766b。中文使用 Microsoft YaHei UI，紧凑控件 12–14px，项目标题 13px。左侧为可滚动文字目录；右侧以图片为视觉主体，项目卡用小标题配多图缩略，不放文件夹图标。顶部单行搜索与分组操作，窄屏换行；选图时展开右侧详情。避免增加大标题和说明卡片。

## 章程核对

仅修改现有扩展与中文说明，不新增框架、云同步、桌面端、测试套件或云资源。质量门槛为相关语法、DOM 接线、清单与构建静态检查；必要浏览器实测仅使用隔离资料及合成图片，不操作用户原图。新增 downloads.open 权限仅用于用户点击打开下载原图。CloudBase 仍为已登记 ArchBuddy/development/archbuddy-api，未部署。

## 验收

- 分类改名、排序在刷新后保留，采集工具及图词库同步。
- 第六份及更多确认方案/版本不会删除前五份，侧栏最近列表最多五项。
- 含“学校、白色、围合庭院、黄昏”等描述的图片能被相关自然句找到，陌生词查询显示无结果；提示词可跨分组查询。
- 项目卡出现预览，点击图片显示右侧详情；生成失败不覆盖手工描述，删除期间不产生孤立结果。
- 单图/整组删除范围明确，取消不变更；原图删除失败保留记录并报错。
- 重新加载扩展后验证系统原图打开、服务生成真实描述与用户目录。未运行项如实记录。
