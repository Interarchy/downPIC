# 采集与图词库导航简化（本地实现）

日期：2026-10-08。分支：direction/plugin。用户选定静态方案一与方案二的组合，并将分类管理统一移到完整图词库左侧，覆盖此前保留侧栏分类入口的选择。

## 目标与用户路径

浏览网页 → 在图片浮框选择分类并保存 → 在图词库集中整理素材与分类 → 从侧栏完成提示词生成或优化。采集保持轻量，管理集中在同一位置，减少入口重复与任务切换。

## 已实现行为

- 浮框右侧使用 Lucide chevron-up 两条斜线图标，悬停提示“收起”。点击收为小 Logo 与“展开”；Logo 在展开和收起状态均直接打开完整图词库，点击“展开”文字恢复原工具；页面内换图保留折叠状态。保留所选分类与已发起的保存任务，不改变总开关。
- 浮框删除“分类”文字标签，保存图片与反推提示词按钮缩窄。总开关仍在浏览器 Logo 菜单；重新启用时恢复展开状态。
- Logo 菜单提供“打开图词库”“打开侧边栏”两个功能入口。
- 侧栏顶部“图词库 / 提示词生成 / 提示词优化”只显示文字。点击图词库直接新开完整页面并关闭侧栏，移除重复大按钮、分类管理区和导入区；旧下载页状态回退提示词生成。当前任务阶段存入扩展会话，关闭侧栏后重开仍恢复生成或优化；显式跳转与隐私确认优先。
- 图库左侧“图库 / 词库”下面、“全部图片”上面增加自定义分类输入，移除框外标题，占位文字为“输入新增自定义分类”。分类右侧提供改名和删除。新增分类后清空搜索及旧详情，选中新分类并设为采集默认分类；分类变更同步已有网页浮框。
- 仅空分类可删除，至少保留一个分类；有图片时提示先将项目拖到其他分类，不因删除分类而删除图片。保留分类排序、项目拖动与历史素材。旧版本曾移除但仍有素材的分类，在改名或移动项目时恢复登记，再调用原有归属校验。
- 右侧详情的元信息仅保留“来源网页、保存时间”，来源在上方可点击，去掉复制按钮，去掉分类和项目名称；图片预览、概要描述及后续操作保留。

## 实现与范围

复用现有 Chrome 本地存储、分类别名、下载索引和来源数据结构。无新增运行依赖、权限或测试框架。Lucide 图形按官方 chevron-up SVG 使用，许可证保留于 content.js；文档检索使用 Context7。

本轮纯本地修改，不涉及云端资源、身份、模型密钥、日志、统计或每日额度；不部署 CloudBase、不发布 Chrome 商店、不提交或推送。上一轮来源网页功能及自动描述队列修复保留。
