# 功能规格：V4 插件内本地网页素材库

**功能分支**：direction/plugin
**创建日期**：2026-09-25；**交互修订**：2026-09-27
**状态**：本地实现与隔离 Chromium 验证通过；待用户本地验收
**输入**：用户确认 V3 已在 Chrome 商店上线并完成验收；V4 先在本地跑通，之后再部署和更新商店。

## 问题与目标

建筑设计师在侧栏完成参考图分析和 Prompt 迭代后，需要回看、检索和整理这些资产。侧栏适合即时任务，不适合宽屏浏览。V4 以插件内完整页面管理现有已确认方案、来源参考图和 Prompt 版本，让用户找到旧素材并继续工作。本轮验证重点是“采集图可按下载目录找回、提示词方案可继续使用”，两类资产在全页明确分区。

## 用户场景与验收

### 用户故事 0：采集图按下载目录找回（P1）

设计师在侧栏首栏“图词库”管理项目类型，从网页图片工具保存图片，点击“打开图词库”后侧栏自动关闭。全页左上以两个精简图标入口切换“采集的图片”和“生成的提示词库”。采集图按项目类型、项目名称逐级展开，左侧只列出项目文件夹名称；右侧先列小标题与缩略图组成的项目卡，打开后显示图片，点击图片在右侧查看详情。项目文件夹多时左侧可纵向滚动。

**独立验收**：
1. 新采集图片保存到电脑时，图词库按同一项目类型与项目名称归类；可读取的新下载显示本地缩略预览；源站读取失败时显示占位，仍可在下载文件夹中定位原图。
2. 同一扩展 ID 的既有 ArchBuddy 下载记录也进入相应目录；旧记录没有库内预览时明确提示，并仍能定位电脑文件。
3. 侧栏首栏可新增、改名、拖动排序、删除和选择默认项目类型；删除类型不影响历史下载目录，网页图片工具仍可采集与保存。打开完整页面后原侧栏自动关闭。

### 用户故事 1：打开并浏览资产（P2）

设计师从侧栏打开本地素材库，在网格中看到已确认方案关联的参考图；选择一张后看到大图、来源名称、所属方案、设计维度和版本。

**独立验收**：
1. 已有 V3 确认方案和来源图时，打开素材库可展示对应图片；不产生新的图片副本或 AI 请求。
2. 图片字节缺失的旧记录仍可见，明确标为“原图缺失”，其 Prompt 与版本仍可查看。
3. 空库给出清晰说明和回到侧栏的操作入口。

### 用户故事 2：整理并找回（P2）

设计师为方案填写项目名称和分类，为来源图填写标签，再用关键词及分类找到它。

**独立验收**：
1. 保存项目、分类和标签后关闭并重新打开页面，内容仍存在。
2. 搜索可以匹配方案名、项目名、来源图名称和标签；分类筛选与搜索可叠加。
3. 输入为空或无结果时有明确反馈，旧方案无需手动迁移即可显示。

### 用户故事 3：回到工作流与维护空间（P3）

设计师从素材库查看 Prompt 历史，复制选定版本，继续在侧栏使用方案；决定删除时明确确认关联图片与版本均会删除。

**独立验收**：
1. 历史版本可只读查看并复制；继续工作不会自动调用模型。
2. 删除只针对选定方案，连同其来源图及版本删除，其他方案保持可用。
3. 页面底部不显示本地存储说明；数据丢失和保留原图的边界由隐私说明与帮助文档承担。

## 边界与异常

- 采集图来自本扩展的下载记录与新建本地索引，按既有下载路径的项目类型、项目名称组织；不自动扫描电脑文件夹；只有用户主动选择 ArchBuddy 下载目录后才读取匹配的旧图片并生成预览，不宣称能仅凭下载记录读取历史图片字节。提示词板块继续展示已确认方案关联的来源图。
- 原图缺失、读取失败、容量不足时保留文本与版本，给出可理解状态。
- 标签、项目、分类属于本地整理元数据，不自动传给 AI 服务。
- 删除必须二次确认；页面打开期间另一处删除或更新同一方案时，应刷新或提示重新载入。
- 当前生成图与完整评估工作稿仍是会话数据，不长期保存到素材库。
- 不做云同步、账户、团队共享、桌面端、批量 AI 分析、行为统计；仅为打开原图增加 downloads.open 权限。
- V4 本轮仅本地开发与验证，不部署 CloudBase，也不上传 Chrome Web Store。

## 功能需求

- **FR-001**：侧栏首栏命名“图词库”，以单个明显按钮打开“图词库”新标签页并自动关闭侧栏；首栏只展示项目类型管理，不展示采集预览。网页图片工具继续负责采集与保存。
- **FR-002**：全页左侧栏左上使用两个小图标入口切换采集图片与提示词库；图片项目类型展开后左侧只列项目文件夹名称，右侧进入文件夹显示图片预览；左侧项目列表支持纵向滚动。提示词卡片在对应图片下直接展示 Prompt 摘要。
- **FR-003**：详情展示图片状态、来源名称、所属方案、当前设计维度、只读 Prompt 版本和时间。
- **FR-004**：方案可编辑项目名称（最多 80 字）与分类（最多 40 字）；每张来源图可编辑最多 5 个标签（每个最多 24 字），空值允许，重复标签合并。
- **FR-005**：支持自然句拆词、建筑同义词与关键词模糊检索、相关度排序及分类筛选；采集图片按视觉描述与项目元数据检索，提示词按正文、历史版本与元数据检索。查询时跨当前板块所有项目或分组。
- **FR-006**：支持复制任一保留版本的完整 Prompt，复制失败时可手动选中。
- **FR-007**：支持明确选择方案继续使用，并在侧栏打开相应方案；不会隐式发送图片或调用模型。
- **FR-008**：支持二次确认后删除完整方案及其本地来源图、版本；不删除下载目录中的文件。
- **FR-009**：页面底部保持简洁，不展示本地存储估算或说明；在隐私说明与文档保留本地数据边界。
- **FR-010**：素材库和侧栏共享 V3 本地数据，旧方案在无新增字段时仍可读取；现有 V3 核心路径保持可用。
- **FR-011**：不新增云端资源、身份、额度规则、日志或统计资源；用户主动生成视觉描述时复用既有图片分析接口与配额。
- **FR-012**：采集图片按下载路径的项目类型、项目名称两级组织，项目内显示多张图片；同一扩展的历史下载可见。
- **FR-013**：可读取的新下载只在扩展本地额外保存限宽缩略预览；读取失败不阻断原图下载，原图仍在电脑下载目录。旧下载缺少预览时提供文件夹定位，不把下载记录误称为完整图片备份。
- **FR-014**：Chrome 141 起支持可靠的侧栏关闭 API；V4 最低 Chrome 版本相应提高到 141，侧栏关闭不新增权限；本轮打开原图增加 downloads.open 权限。
- **FR-015**：Logo 弹窗提供反推提示词、效果迭代优化、图词库三条统一绿色的打开入口和网页图片工具开关；侧栏首栏可新增、删除、选择项目类型，删除不改变既有下载记录。
- **FR-016**：已下载但缺少库内预览的旧图片，在用户选择电脑上的 ArchBuddy 下载目录后按完整相对路径匹配并生成本地预览，不上传原图、不改变下载目录。
- **FR-017**：提示词图片卡可由用户多选，建立命名分组、移动到已有分组、重命名和删除分组；左侧分组名称及数量与右侧卡片一一对应。删组仅让卡片回到“未分组”，不删除方案、图片或 Prompt。

## 关键实体

- **提示词方案**：方案 ID、名称、项目名称、分类、确认时间、来源图引用、版本。
- **来源图**：来源图 ID、归属方案、名称、状态、图片大小、标签；完整图片只保留一份。
- **Prompt 版本**：版本 ID、编号、时间、只读正文和关联来源图 ID。
- **采集下载**：Chrome 下载 ID、项目类型、项目名称、文件名、下载时间及可选的本地缩略预览。

## 成功标准

- **SC-001**：用户在本地演示中从“图词库”首栏打开全页，侧栏关闭；能按项目类型和项目名称找到已采集图片，并切换到提示词板块查看方案。
- **SC-002**：用户在重新打开页面后仍能通过项目、分类或标签找到已整理资产。
- **SC-003**：用户能复制历史 Prompt，并从素材库返回侧栏继续处理同一方案；分组操作不会改变 Prompt 版本。
- **SC-004**：删除一份方案后，其图片与版本不再出现；另一份方案内容保持不变。
- **SC-005**：上述浏览、整理与删除操作不触发模型请求或云端素材写入；本轮静态检查通过。

## 假设与依赖

- 图词库包含本扩展采集的下载图片与已确认 Prompt 方案两类资产；单次构建最多 3 张参考图；取消方案及版本的五份存储截断，侧栏只展示最近五份；容量不足时报错，既有记录不被自动淘汰。
- 首版项目名称、分类为方案级，标签为来源图级；无值时不显示伪造的项目或类别。
- 完整的系统文件管理、导出与导入备份，依据本地图词库的实际使用反馈另立需求；当前仅通过浏览器下载记录和本地索引展示采集图片。
- 依赖 V3 已有的本地方案存储、来源图仓库与删除路径。

## 2026-09-27 增补要求

- **FR-018**：顶部用搜索框替代大标题；提示词搜索、新分组和移入分组同一行，空间不足时换行。完整方案的固定生成准则保留，卡片摘要优先展示有区分度的视觉维度。
- **FR-019**：点击采集图片显示右侧详情、可编辑核心视觉描述、生成描述、保存、原图打开和删除。生成仅在用户点击后调用既有服务，并检查初次图片处理同意；失败保留旧描述。
- **FR-020**：分类改名和拖动顺序在采集工具、侧栏及图词库中保持一致。改名保留历史文件物理路径，通过本地名称映射归并显示。
- **FR-021**：全部确认方案及版本在本地保存；侧栏最近列表最多五项，网页包含全部方案。“开始评估”点击即为明确发送动作，移除重复勾选框。
- **FR-022**：单图与项目图片可在确认对话框中选择仅移出图库或同时删除下载原图；仅接受本扩展 ArchBuddy 路径下载。部分失败报告数量，原图删除失败不把该条目标成删除成功。删除项目图片后图库项目消失，电脑空文件夹保留。
- **FR-023**：downloads.open 仅由用户点击打开原图时使用系统默认程序；页面预览仍为库内缩略图。原图已移动、删除或打开失败时提供反馈。
