# 2026-09-28 本地混合向量检索 B 方向

## 核心路径

输入关键词立即显示本地匹配 → 回车后生成一次查询向量 → 与插件本地素材向量计算相似度 → 合并去重并展示。图片下载后的自动视觉描述与已确认提示词是索引文本来源；描述变化只更新受影响项。首次确认后为既有文字素材分批建立索引。

## 范围与数据边界

- 不创建 CloudBase 向量库或素材云仓。索引存于扩展 IndexedDB，按图库/词库区分，记录素材 ID、文本 SHA-256、模型版本和 1024 维 Float32 向量；不在索引中重复保存正文。删除记录时清理对应向量。
- 用户对新增第三方处理单独同意后，ArchBuddy 服务把每批最多 32 条、单条最多 2000 字的名称/分类/描述或提示词文本交给 TokenHub；查询只发送一次。绝不发送图片、下载路径、来源网址或整库向量。服务不持久化请求正文或向量。
- 复用既有匿名会话、请求 ID、全局并发及个人 20/项目 200 日额度；向量接口独立每分钟默认 20 次的速率上限。TokenHub Key 仅在服务端进程环境变量，本机开发可由当前 Windows 用户加密配置加载；2026-09-28 本地真实调用通过，云端仍未配置，不使用其他项目资源。
- 向量相似度只重排文字描述的相关性；不承诺识别无描述图片的视觉内容。保留关键词即时结果；向量服务未配置、失败或额度不足时明确提示并保留关键词结果。可选大模型重排暂不实现，待真实检索样例评估必要性。

## 质量与发布门槛

- 遵守章程：优先复用现有接口身份与额度，修改范围限搜索链路；运行相关语法、现有扩展与服务检查，不新增测试文件或框架。
- 用合成语料验证首次建索引、文本变更增量更新、重复搜索复用本地向量、一次查询向量、关键词与向量合并、删除清理和失败回退。
- 上线前验证 TokenHub 凭据、实际延迟/召回、费用、公开隐私站与 CloudBase 项目隔离；未完成前保持本地状态，不改商店版本。
