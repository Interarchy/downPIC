# V4 本地验收

1. 确认本地 API 在 http://127.0.0.1:8080 运行；当前源码 BACKEND_MODE=local。Chrome 扩展管理页重新加载本仓库 extension/，注意新增“打开下载文件”权限；不要加载旧 ZIP。
2. 点击 Logo 核对“打开/关闭图片浏览器下载浮框”、反馈提示词、提示词迭代优化、打开图词库。三个功能按钮保持绿色。
3. 侧栏三栏为图词库、提示词生成、提示词优化。图词库中改名项目类型、拖动左侧把手排序，刷新后保持；网页采集工具同步新名称和顺序，已下载文件物理路径不改名。
4. 在提示词优化中确认“开始评估”无需额外勾选；最近确认列表最多五份。新增第六份后，在全页提示词库“全部提示词”仍能找到所有方案及版本。此前旧版已淘汰的内容无法找回。
5. 图词库采集图片左侧为文字目录，可滚动；右侧项目卡显示小标题和缩略图。旧图无预览时点“关联图片预览”，选择原始 ArchBuddy 下载目录。
6. 打开项目后点击图片，在右侧查看详情；点击“生成视觉描述”会发送当前预览给既有 AI 服务，生成后自动保存，允许手工编辑再保存。没有预览的旧图先关联目录。
7. 搜索“夕阳下有院子的白色学校”“鸟瞰混凝土建筑”等自然句，按名称、已保存描述、Prompt 与常见建筑同义词匹配。输入查询时跨当前板块所有项目或分组；未生成/填写描述的图片只能按已有名称等元数据匹配。
8. 双击图库图片卡或点击详情图应直接调用默认图片程序。若原图移动或删除，使用“定位文件”核对路径。系统窗口显示仍需用户本机验收。
9. 请仅用可丢弃素材验收删除：先取消，再仅移出图库，最后勾选“同时删除电脑中的下载原图”。整组操作显示张数；移出图库不会删原图，删除原图不可恢复；电脑上的空文件夹保留。
10. 提示词顶部搜索、新建分组、移动到分组处于同一行。可从搜索结果多选建组，清空搜索或点击左侧组查看成员。卡片展示视觉内容摘要，详情保留完整 Prompt 与所有版本。
11. 本轮仍为本地验收。提交或上线前恢复源码 cloud，按发布检查同步公开隐私政策与权限披露，再更新商店；当前没有新增 CloudBase 资源或后端部署需求。


## 2026-09-28 本地验收入口

1. 本地服务使用 cloudbase/scripts/start-local-v3.ps1，保持 8080 运行，源码 runtime-config 为 local。
2. chrome://extensions 重新加载 extension/（新增 alarms 权限），关闭旧图库页再从插件打开。
3. 首次在图库点“开启图库 AI”，确认后下载一张新图片，描述后台自动保存。旧图可填写描述或生成完整提示词获取摘要。
4. 顶部写自然语言需求，按回车或点搜索；观察语义结果及异常提示。图库与词库各自搜索该板块全部资产。
5. 单击图片查看详情，双击采集图应直接请求系统默认看图软件；图片右上垃圾桶可删除，详情提供生成完整提示词及打开原文件夹。
6. 拖动左侧项目类型，再刷新核对顺序；检查窄侧栏和图库／词库短标签。
7. 插件侧栏向下滚动，顶部品牌及三栏应固定；提示词优化顶部的 Gemini、ChatGPT 链接打开对应官网。
8. 自动描述与语义检索共用模型调用限制；关闭侧栏详细说明中的图库 AI 开关可停止新自动处理。

此时不要用旧的商店 ZIP 替代源码验收；云端旧 API 尚不提供本轮接口。

## 2026-09-28 文件夹导入与搜索补充验收

1. 在侧栏“图词库”或完整网页“图库”点“导入本地文件夹”，选择一个项目类型文件夹。例如 `学校建筑/教学楼方案/01.png`：学校建筑是一级类型，教学楼方案是二级项目。源目录里的图片不会被移动；单张支持 PNG/JPEG/WebP 且不超过 10 MB。
2. 在网页左侧展开类型、右侧打开项目，核对图片预览与双击大图；再次导入同一文件夹应报告跳过重复项。同名一级类型新增项目或图片时应合并显示。
3. 将左侧项目名称或右侧项目缩略卡拖到另一一级类型，观察目标高亮和刷新后归类。若目标已有同名项目，图片显示在同一个项目下；电脑原目录保持原位。
4. 输入一个文件名或已填视觉描述中的词，不按回车应立即看到关键词结果。按回车或点搜索后，状态提示语义结果补充；无关或语义请求失败时已出现的关键词结果仍保留。导入图片不自动批量生成描述，可在单图详情填写描述后继续验收自然语言检索。
5. 用可丢弃图片验收导入副本删除：删除弹窗不提供删除电脑原文件选项，删除后原电脑文件仍存在。下载图片的原图删除选项仍仅作用于已登记的下载文件。

本轮仍为本地源码状态；语义部分要求本地 8080 服务运行，尚未部署更新云端和商店。

## 2026-09-28 系统看图软件补充验收

1. 在网页图库进入包含多张导入图片的项目。单击图片卡打开右侧详情，再单击详情图；或直接双击图片卡。此时直接请求系统默认看图软件；导入图首次查看会准备同一项目的系统查看副本。若浏览器因准备耗时阻止自动打开，按界面异常提示重试。
2. 在系统软件中尝试左右浏览同一项目图片；具体快捷键与排序由电脑默认程序决定。再次打开同一导入图应复用已准备的副本。
3. 在下载目录核对独立的 `ArchBuddy-系统查看` 文件夹；源导入目录中的图片保持不变。删除图库里的可丢弃导入图后，对应系统查看副本应清理；若被看图软件占用，界面会提示手动清理。
4. 插件下载的图片直接使用原下载文件；右侧详情图单击直接请求系统打开。此次仍是本地功能，尚未更新商店。

## 2026-09-28 多文件夹批量导入补充验收

1. 在电脑文件管理器中同时选中两个一级文件夹，拖到侧栏“图词库”或完整网页“图库”的导入区。各文件夹应分别成为项目类型，二级目录仍为项目名称。目录选择按钮仍可用于选取文件夹。
2. 一次拖入两个同名一级目录（可来自不同上级目录）时，项目应合并；再次拖入已导入图片应显示跳过重复数量。大目录应能读完多批条目，不只导入前 100 个。
3. 核对电脑源目录未移动；导入不会自动批量发送图片到 AI。此轮本地隔离浏览器只用合成文件核对了多目录及同名去重，真实文件管理器拖放仍待用户本机验收。

## 2026-09-28 大图左右浏览修订验收

1. 进入至少有两张图的同一项目，双击图片卡或单击右侧详情图。网页内大图应出现图片名、位置计数与左右箭头；方向键和按钮均可切换，首尾按钮置灰。打开与切换时不应生成新的浏览器下载。
2. 在搜索结果打开大图，左右浏览范围应是当前搜索结果。词库图片的大图仍保持原有单图查看。
3. 仅点击大图里的“用系统看图软件打开”才请求电脑默认程序；导入图此时可能在下载目录生成 `ArchBuddy-系统查看` 副本。普通大图查看不写入下载目录。

## 2026-09-28 直接系统查看修订验收

1. 在图库项目中双击图片卡，或单击右侧详情图，应直接请求电脑默认看图软件，不出现网页大图，也不需要先点击“用系统看图软件打开”。下载图使用原下载文件；导入图首次可能先准备 `ArchBuddy-系统查看` 副本。
2. 再次查看已准备的导入图，应复用副本并直接调用系统打开。若首次准备超过 Chrome 允许的用户手势时间，页面只在异常时提供重试；默认看图软件的真实窗口和左右浏览能力需要在用户电脑上核对。
3. 上一节“页内大图左右浏览修订验收”是历史方案，已由本节替代；词库图片的页内单图预览未改。
