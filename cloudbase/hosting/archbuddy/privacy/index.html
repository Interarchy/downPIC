ArchBuddy 隐私政策

更新日期：2026 年 9 月 28 日

ArchBuddy 只处理用户主动选择、粘贴或下载的参考图片，用于提供图片下载、分类和中文结构化提示词反推功能。我们不进行广告追踪、行为画像或后台浏览记录收集。

我们处理的数据

下载功能会在用户设备本地使用所选图片、当前网页标题、来源地址和用户选择的项目类型，用于生成下载目录和文件名。提示词反推功能会处理用户主动选择、粘贴或拖入的图片。

图片分析与第三方处理

只有在用户主动点击反推并确认图片处理说明后，所选图片才会发送至 ArchBuddy 服务，再由服务调用 DeepSeek API 生成中文结构化提示词。网页浏览历史和其他未选择的网页内容不会随图片发送给模型。

ArchBuddy 服务不持久化保存原图或提示词正文，图片只在完成分析所需的请求过程中处理。DeepSeek 对数据的处理同时受其服务条款与隐私政策约束。

可选图库向量检索

用户另行确认后，ArchBuddy 仅将图库图片的名称、分类、视觉描述及词库提示词文本，在首次建立索引或文本变化时发送给腾讯云 TokenHub 生成文本向量；用户提交搜索时只发送本次查询生成一次查询向量。图片字节、下载路径和来源网址不发送给 TokenHub。向量索引保存在用户浏览器的扩展 IndexedDB 中，关键词匹配、向量比对和结果合并也在本地完成。ArchBuddy 服务不持久化这些文本或向量，不记录请求正文。此处理使用现有匿名额度；用户可关闭图库 AI 停止新请求。公开网页的更新不代表尚未部署的扩展功能已上线。

匿名身份与额度记录

扩展首次使用时会在本地生成随机安装标识，并向 ArchBuddy 服务换取短期匿名访问凭据。服务端将其转换为不可逆的匿名标识，用于执行每日额度、防止重复请求和必要故障排查，不保存原始安装标识。

额度和请求记录可能包含匿名标识、日期、请求摘要、成功或失败状态、处理时长及模型返回的数值 Token 用量，不包含图片、提示词正文、网页地址、下载路径或自定义分类文字，保留期限不超过 30 天。

模型凭据

DeepSeek、TokenHub API Key 和服务签名密钥只保存在 ArchBuddy 服务端，不包含在扩展、网页、下载文件或用户浏览器存储中。用户无需输入模型密钥。

本地保存与删除

分类设置、隐私确认、随机安装标识、最多 5 份纯文字意图草稿和匿名统计选择保存在 Chrome 本地扩展存储中；当前参考图和短期匿名凭据保存在会话存储中。草稿不包含图片或来源网址。卸载扩展可清除这些本地数据。下载的图片保存在用户的 Chrome 下载目录中，由用户自行管理和删除。

可选匿名改进统计

匿名统计默认关闭，用户可在侧边栏主动选择加入或随时撤回。加入后仅记录分析开始、成功或失败类别、模块编辑或停用、Prompt 确认与复制等白名单事件，以及服务端派生的匿名标识和时间，保留不超过 30 天。不会记录图片、网址、Prompt、模块正文、证据、自定义分类、文件路径、Cookie、令牌、原始安装标识或直接身份。撤回后停止发送新事件，既有记录按保留期删除。

数据用途限制与安全

ArchBuddy 不出售用户数据，不将数据用于个性化广告、信用评估或跨站追踪，也不允许人工读取用户图片。ArchBuddy 对用户数据的使用遵循 Chrome Web Store 用户数据政策，包括其中的 Limited Use（有限使用）要求；数据只用于提供或改进本政策所述的用户可见功能及必要的安全与故障处理。图片通过 HTTPS 传输；服务端日志不记录图片正文、提示词、模型密钥或访问凭据。

版权与授权

ArchBuddy 不绕过登录、付费墙或网站访问限制。用户应确保有权访问、保存和处理所选图片，并遵守来源网站条款和适用法律。
